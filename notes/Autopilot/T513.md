**The zone string is a sky file.** The loader key is `UnderwaterSkyFile` and the 138/3 handler
keeps it next to the saved current sky name, so it is a sky-file name. The reader of +0x1D0 was
not found; I searched `0x00b64360` (underwater on/off), `0x00b6bb90` (SetActive), `0x00b64580`
(state setter), `0x00b67b80` and `0x00b6c290` (frame updates). `underwater_sky` stays `''`.
Lxzxrus sends the scene name there (75f7d95 `FishingSession.cs` RegisterResponse). That is a
scene name, not a sky file, and we do not copy it.

**Zone config is per encounter.** `0x01079260` looks rows up by `EncounterDefId`, so the original
server had one zone block per fishing hole. That matches sending per-hole values.
