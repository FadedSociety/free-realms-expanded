## Security note

A hostile client can forge Type8 board messages, but the server accepts only
idle selectable chains and goal tiles actually present on the bottom row; it
does not accept client scores or reward claims. The bundle gate is build-time
content validation, not a network trust boundary. It now refuses package
bindings that would make the server reject startup or send mismatched encounter
frames, and all refusal tests check that content is unchanged. No client-supplied
item id, quantity, result or payout is trusted by this diff; the new end-to-end
test receives grants only after the server validates the board and quota state.
