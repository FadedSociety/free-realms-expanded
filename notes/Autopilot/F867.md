## Security threat note (secure-code-guardian)

No parser, wire field, save shape, coin/item path or client-controlled quantity changed;
the diff is test support plus content text. The attack surface is the existing 26/8 pickup
click and the 49/x offer/turn-in:

- A hostile client can send 26/8 for any guid from any claimed position. Production
  refuses an unknown/unshown guid, a busy player, a non-open world or out-of-range click,
  and a node type no open objective wants, each with one 15/3 line and no state change.
  `refused_without_change` and `assert_no_offer` assert the refusal's `changed == false`,
  no 35/3, and byte-identical serialized state.
- The pickup count is the server's own event count, capped at the goal quantity; no packet
  supplies a count, an item or a reward. Every new node type has an empty drop table, and
  the loader refuses a quest node type with drops.
- The shared `said`/`removed` are test-only readers of server-emitted 15/3/35/3 packets;
  they never feed production. `collect` reads production `counts` and server replies only.
- No secret, key, account data or absolute path is in the diff.
