## (R) rules

- The once-per-second poll remains reconstructed `(R)` (human-paced admin edits;
  no content schema for watcher tuning).
- A refused file is retried only when its mtime changes `(R)`: the refusal is a
  property of that file stamp. The mtime-granularity ceiling (two writes inside
  one filesystem clock tick) is unchanged; tests wait one tick.
- The acting session's own write is applied with the same canonical swap as a
  reload `(R)`; the remove/re-add churn of unchanged placed rows is accepted to
  avoid a second apply path.
- A missing placement file means "no placed actors" `(R)`; a malformed,
  oversized or non-regular one is refused, not treated as empty.
- A movie-handler error ends only the sending session (existing T253 rule,
  unchanged); the isolation test now refreshes the other sessions' liveness so
  the 60 s idle rule is not what ends them.

## Security threat note (secure-code-guardian)

- A hostile client still cannot write `npc_placements.json`: only the
  role-checked `realm place`/`realm unplace` and local tools write it. The watch
  re-reads the same file every session already loads at login and adds no
  client-supplied field, packet writer or broadcast.
- The watch treats the file as untrusted input on every poll: at most 16 MiB,
  must be a regular file, must be the `Rows<Placement>` schema; a parse/IO
  refusal publishes nothing, keeps the previous view and revision, and logs once
  per stamp instead of propagating out of `Gameplay::tick`. Non-finite positions
  are still skipped by the existing `place()`.
- Every command that reads the table (`place`, `unplace`, `placements`) refuses
  a table it cannot read before allocating an id or writing; the refusal changes
  no file, character state or view. `realm reload placements` uses the same
  reader.
- No coins, items, rewards, roles, chat or saves are read or granted;
  `Outcome::changed` stays false, so no character save is triggered. Placement
  rows are admin-authored and their AddNpc/RemoveNpc bytes are the existing
  server builders.
