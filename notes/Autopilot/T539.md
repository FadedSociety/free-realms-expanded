## Security threat note (secure-code-guardian)

The new content adds no parser, no wire field and no client-controlled quantity; the
attack surface is the existing 26/8 pickup click and the existing quest packets:

- A hostile client can send 26/8 for any actor guid from any claimed position. The
  server refuses an unknown/unshown guid (`Gone`), a busy player (`Busy`), a non-open
  world or out-of-range click (`TooFar`), and a node type no open objective wants
  (`NotNeeded`) with one chat line and no state change. Only a matching open
  `collect_node` step can credit a pickup; the count comes from the server event, not
  from the packet, and is capped at the goal quantity.
- Forged 49/2 accepts and 49/14 turn-ins are still gated by the quest engine’s
  eligibility, pending-offer and pending-turn-in rules; the early-49/14 test asserts
  one such refusal changes no byte.
- The node consume and objective credit are staged on a clone and committed only
  after the quest event succeeds; refused clicks leave the save byte-identical.
- Nodes and visibility are per-session: one player’s pickup cannot credit or hide
  another player’s node (`two_players_are_independent`).
- No secrets, keys, account data or absolute paths are in the diff.

   serialized state, click, assert the “not needed” line and `saved == before`;
   `follow_ups_wait_for_their_prerequisite` uses the shared `assert_no_offer` (which
   also checks byte equality), and the early 49/14 uses
   `assert_packet_changes_nothing`. Canary: see the test section.
2. **Rollback covers all state.** No new transaction or shared side table. The
   production pickup stages a clone and commits after the quest event; the refusal
   tests assert the serialized state is unchanged. No `Rc`/`RefCell`/`Arc` added.
3. **Apply deltas, never restore snapshots.** No payout or exit code changed.
   `ZoneQuests::turn_in` pays through the existing reward applier and the test asserts

   `Gameplay::activity_busy`/`Occupation` gate; `quest_pickup_nodes::pickup_refused_out_of_range_or_busy`

   Quarry; Nomi opens Homework after Little Brother) and the negative gate (Box is
