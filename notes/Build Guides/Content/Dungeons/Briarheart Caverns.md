## Conflicts

1. **Wiki enemy list.** The wiki names Changelings, Berserkers and Wolves. The client text adds elementals and ninjas (see Enemies). Client text wins; the actual spawn table is unknown.
2. **Item name.** The wiki writes "Pinhole Archer Boots" and "Enery Transfer" in the bonus list. The client spells them "Pin Hole Archer Boots" and "Energy Transfer". Client spellings are used above.
3. **Campaign gate.** The client blurb reads like a dungeon campaign gate ("Make sure you have already completed Campaign 2: Haunted Mines"). The video evidence ([[Haunted Mines]] makes the same case) places the campaign list inside the Treasure War card game, so it is reworded above as unproven and not a gate. Wiki is silent. Unresolved without a client mapping of the campaign feature.
4. **Item name.** The wiki's Brawler bonus set "Bare Knuckle" is spelled "Bare-Knuckle" in the client (`loc 950110269`, "Bare-Knuckle Brawler Jacket"). The client spelling is used.
5. **Goal wording source.** "Bonus: Defeat all enemies!" is wiki-only. It conflicts with nothing, but it is the weakest goal text in this guide.
