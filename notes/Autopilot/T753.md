## Security note (secure-code-guardian)

- **Surface.** No client packet reaches this module yet; it is server-side content and a
  pure lookup. Later slices pass a server pose (`movement.rs`) to `region_at`/`place_at`;
  the client never supplies the region or place. A forged client zone/region field cannot
  select a row because the lookup only accepts the table's world zone and derives both
  values from `x`/`z`.
- **Hostile content is refused, not partially applied.** Unknown fields are denied, ids
  are unique, name ids must be in the recovered client-locale set, shapes must be finite
  and bounded (|coordinate| <= 20,000), spheres have a positive radius, rectangles are
  ordered, caps are 16 zones / 256 places / 4,096 shapes / 256 name ids, every row needs
  `source`, exactly one world zone with id 0 and captured geometry 2, exactly ten regions
  1..=10, region 1 has no banner and 2..=10 need a bounded `.swf` key. A malformed file
  refuses the session load; the reload transaction stages on the `Gameplay` clone and
  commits `npc_visibility` only after every step succeeds.
- **No panic on a client value.** `region_at`/`place_at` return `None` for a non-finite
  coordinate, an unknown zone or the open map; there is no `unwrap` of client data and no
  allocation in the lookup.
- **No secrets/player data.** The data and tests contain client place/region names and
  locale ids only; no player names, chat text or save data.
- **Abuse scope.** Nothing in this slice is player-triggerable beyond a later position
  lookup; no rewards, coins, items, roles or persistence.
