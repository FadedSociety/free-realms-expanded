# S0310 native map findings

## Range and structure

This shard covers a cluster of shared container and UI callback code. The keyed hash-list helpers at `00a8ce60`–`00a8cfc0`, string-key registry routines at `00a8d610`–`00a8d6f0`, and `UIProcessor` virtual at `00a8d500` manage retained objects and keyed entries. The red-black tree operations at `00a90940`–`00a90e90` feed a tracked node-block/free-list pool at `00a91040`–`00a91230`; the pool adjustor thunks at `00a912a0`/`00a912b0` bind it to `SoeUtil::HashList<MinimapIndicatorEntry,64,32>`. RTTI evidence also binds this range to `MinimapIndicatorEntry`, `TextureAssetTrackingNode`, and their map/list cleanup and lifecycle methods (`00a8f520`, `00a8f550`, `00a90810`, `00a912c0`–`00a91380`, `00a91a40`–`00a91aa0`). These functions identify container ownership and data maintenance; they do not establish the full asset-tracking policy.

## UI and script callbacks

The named handlers at `00a8de60`–`00a8e3e0` update combat-group health/power and player membership; `00a8ec00`/`00a8ee30` add/remove group ability effects. Minimap callbacks kill/select indicators and refresh tracked positions (`00a8e540`, `00a8e660`, `00a8e860`), and place indicators for generic, friend, group-member, and guild-member records (`00a8fc80`, `00a90070`–`00a90430`). `00a8e860` uses the elapsed guard `0x14d`, re-resolves actor keys, removes flagged missing entries, and sends changed X/Z coordinates to the Lua callback string `MiniMap:UpdateIndicatorLocation`. The range also contains a timer callback (`00a8eff0`), quest objective/helper handlers (`00a8f130`, `00a8f2b0`), an achievement objective callback (`00a8f3b0`), and task selection (`00a8fab0`). The quest-journal behavior agrees with `notes/Research/Native Quest Journal UI.md` at `00a8f130`/`00a8f2b0`.

It does not establish authorization, an allowed script set, or original server behavior.
