## Why 3050021 stays off

- The dishes are recipes 43, 46, 50, 51, 56 and 59 (`data/content/recipes.json`). A 26/24 start for a recipe
  the character has not learned is refused (`NotLearned`), and `Gameplay::learn_recipe` needs the recipe's
  pattern item (`recipe_item_definition_id`): 55825, 55826, 55827, 55828, 860 and 861.
- No source for those pattern items exists in the shipped content: no vendor or store row, quest reward,
  objective, or node drop table lists them (the only hits for the same numbers are unrelated: collection spawn
  ids, a store price, quick-chat keys, and the recipe book and startup item catalogue themselves). The client
  item evidence does not say how a player gets a pattern either (citems.json: pattern acquisition not
  evidenced). The first attempt's note that the pattern items "appear in other NPC rows' vendor stock" was wrong.
- It would have been the first enabled `craft_recipe` quest in the repo, and its test only passed because it
  seeded `learned_recipes`, which a real Chef never has.

`learning_to_crave_the_flave_stays_off_until_its_patterns_have_a_source` pins the row off and walks every
shipped content JSON (except the recipe book and the startup catalogue) for the six pattern ids by shape: a
single-id key (`item_id`, `item_definition_id`, `definition_id`, `resource_id`) or an item-list key (`items`,
`*_items`, `*item_ids`: vendor `item_ids`, encounter `reward_items` as `[id, count]` pairs, pet `items` and
`adoption_item_ids`, staff `default_items`). A bare number under a list key (a vendor count) is ignored. Review
found the first version saw only the single-id keys, so a vendor row would have passed silently. When a source lands the test
fails with the file name, so the row is re-checked. To enable it then: the six `craft_recipe` objectives from
the first attempt (text ids 140400, 140402, 140406, 140408, 140410, 140412, then the review Talk 140414, spec
`objective-specs.json q3050021`) plus a test that starts from an **unseeded** Chef and cooks all six through
26/24. An alternative that needs the lead's design call: an (R) grant of the six pattern items when Cloo's quest
is accepted.
