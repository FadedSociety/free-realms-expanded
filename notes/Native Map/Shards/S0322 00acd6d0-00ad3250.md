## WelcomeInfo data sources

- Four WelcomeInfo data-source classes expose column labels for What's New, Info, Claim Codes, and Latest Content (00ace460..00ace560, constructors 00ad0a70..00ad0e60).
- 00ad0100 reads welcome.txt: it skips # rows, treats : as a marker, stores wide-string rows, and compares two identifiers from & rows against current client fields before updating data. The meaning of those identifiers remains unknown.

- 00ad0880 converts two values to wide strings, supplies the localized "Message of the Day" label when the first is empty, and updates an existing matching row or appends a new one. 00ad0000 calls Lua OnShowWelcomeScreen when its pending flag is set.
