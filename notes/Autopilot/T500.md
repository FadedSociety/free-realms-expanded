## Threat note (secure-code-guardian)

A hostile client can send 49/2 for an unoffered or prerequisite-locked quest (A Reliable Source),
49/14 before the steps, twice, or for a quest never accepted, a menu turn-in early, or a Talk to an
out-of-order target. Every path goes through the unchanged `QuestEngine` gates (`can_offer`,
ordered objectives, `begin_turnin` completeness), and the tests assert each refusal leaves the
serialized save byte-equal. Rewards are fixed content values (at most 36 coins and 30 XP per quest),
paid on the server-judged turn-in only. The extra-spawn Talk maps the runtime guid to the content
key server-side (`NpcVisibility::content_key`); a client guid that is not in that map is refused as
an unknown runtime guid.
