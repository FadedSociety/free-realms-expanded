### Threat note

No client input reaches this change: it is server content plus a generator.
- **A coin claiming a second entry.** The loader refuses a duplicate guid or entry, an entry outside the
  catalogue, a wrong owner, and a tier/collection mismatch (existing refusals; the T449 refusal tests still pass).
- **A guid that aliases another actor.** The new actor-id check fails the content test on any guid that names
  two spawns (canary 1).
- Pickup (T450, merged) checks range and visibility server-side; the map only names the entry, so a hostile click on
  these guids is refused exactly like any other coin's.
