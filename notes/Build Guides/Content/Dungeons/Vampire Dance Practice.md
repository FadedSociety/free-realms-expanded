# Vampire Dance Practice

Part of [[Content]] › [[Dungeons]]. Tags: **[client]** = game locale text (`loc <id>`), **[video]** = player recordings (frame key), **[wiki]** = fan wiki. Precedence client > video > wiki.

> Vampire Dance Practice is a **seasonal special-spawn battle**, not an Atlas dungeon. The wiki files it under *Battle*, *Special Spawn*, *Super Spooktacular*, *Seasonal* and *Blackspore*. It is the werewolf team's half of the Halloween vampire-versus-werewolf story; its twin is [[Werewolf Dance Practice]]. [wiki]

## Conflicts

1. **Sticker versus Stand-Up.** The wiki's [[Werewolf Dance Practice]] page lists "Sticker" forms of three items that this page lists as "Stand-Up". The client has only the "Stand-Up" names (`loc 1889624620`, `1458878127`, `611651650`). Every name on this page matches the client.
2. **Enemy name.** The wiki writes "Vampire Break Dancers". The client singular is "Vampire Break Dancer" (`loc 1963231226`). The client form is used.
3. **Quest-to-battle link.** The wiki's series order and the client's speaker text do not state which quest title owns each description. Left as inference above.
