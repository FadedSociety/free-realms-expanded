## Security note

A hostile client can replay `41/108`, forge another actor GUID, or claim a
reward. Level comes only from server-owned job experience, rewards come only
from the encounter engine's server-owned kill count, and the pending battle id
is server state. A low-level Go returns before consuming that pending state or
entering `begin`; `begin` repeats the same guard for other callers. A forged
marker GUID that is not a field battle creates no pending state and no reward.
The shared entrance GUID is a recovery binding, not client-supplied identity.
