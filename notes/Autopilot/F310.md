## Security note (secure-code-guardian)

Threat: a hostile client can send, while a movie is live, the five blocked
families, arbitrary `realm ` text (including `status`), a 26/42 with a trailing
byte, or arbitrary 39/x frames.

- Every refusal path returns the same fixed server text and stages nothing:
  the new non-ignored Type8 test compares `gateway.snapshot()` before/after
  each family and `realm status`; the existing close test compares the whole
  snapshot after the malformed close. Values are server constants, not client
  echoes.
- The new forged test data is a committed synthetic harvesting board with no
  goals, outputs or item grants (F327 moved it to
  `tests/fixtures/movie_harvesting.json`); it cannot pay a player and is
  test-only.
- No new `unwrap` on client-controlled data; the movie gate still checks length
  before parsing, and the isolation test drives the real transport containment
  (`Server::step` ends only the faulted session).
- The isolation retry is bounded (50 × 2 ms) and suppresses the world tick
  while retrying, so a slow loopback datagram cannot be confused with a tick
  fault; a missing datagram fails the test rather than passing silently.
- No player names or player-authored chat text were added to code or notes.
