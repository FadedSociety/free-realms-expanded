## Root cause notes

- **Out-of-range Go** (`src/encounter/field.rs:561-568`): the pending battle is
  session state (`EncounterEngine::pending_battle`, not part of
  `EncounterState`/`GameplayState`), so the save is equal before and after; the
  old T354 test could only see the save, which is why it missed the drop. The
  new replay assertion observes the drop through the request path.
- **Health scaling** (`src/encounter/field.rs:356-364`): the loader scales enemy
  health/damage by `level_health(difficulty_level(difficulty)) / 1000`; only
  difficulty 1 is exactly 1.0. The shared `enter_battle` now states that rule
  next to the assertion it conditions.
