## Classes and subsystems

This range is mostly `engine.containers` code instantiated for GameCommerce marketing/store data (`game.coinstore`). It includes a `MarketingDataHandler` destructor at `00c35710`, store-definition map constructors and node allocators, linked hash-list operations, and red-black-tree/pool helpers. The separate `InGamePurchaseGiftRecord` map at `00c34250` is generic map cleanup; its type alone does not establish purchase behavior here.

Definition maps include store bundle groups keyed by `StoreBundleGroupId` with 16 buckets (`00c34bd0`), category groups and shortcuts with 64 buckets (`00c34c00`, `00c34c30`), portal categories with 64 buckets (`00c34c60`), billboard definitions with 64 buckets (`00c34ca0`), billboard panels with 16 buckets (`00c34d30`), and bundle category-tree nodes keyed by `StoreBundleCategoryId` with 128 buckets (`00c34ea0`). App-store bundle definitions use a 2048-bucket map and a 512-slot pool (`00c39080`); the pool allocates 0x130-byte slots and releases a block when every slot is free (`00c39850`, `00c39970`, `00c399d0`, `00c39a40`). The large allocator sizes and bucket counts are implementation facts, not evidence of retail catalog contents.

Billboards contain an inline-capacity-four panel array. The array grows in 0x5c-byte element steps (`00c36230`, `00c37350`, `00c37380`); its typed element constructor identifies `AppStoreBillboardPanelDefinition` (`00c35140`, callee constructor `010863e0`). Billboard validity requires positive values at offsets 4, 8 and 0x14, then requires every panel validator to pass (`00c37490`). Its debug formatter prints billboard id, location id, panel count and panel strings (`00c38cb0`). Relative-time formatting at `00c34880` selects localized year/day/hour/minute keys and a less-than-a-minute path (`ui.locale`).

## How the pieces connect

`00c387f0` validates shortcut targets by type: type 1 resolves a bundle, type 2 calls the external store-entry lookup `0099d6f0`, and type 3 checks a 128-bucket key map. Other values log `Invalid store shortcut type, shortcutId=%d, storeId=%d.` to `MarketingDataDefinitions.log`. Store and bundle lookup helpers `00c388b0` and `00c38910` search a store entry then scan its 2048-bucket bundle map. The surrounding callback `00c3b720` resolves a bundle, checks `00c36f80`'s referenced-bundle predicate, then invokes tree processing; missing content follows a log path. This ties definition lookup, dependency checking and content publication together, but does not reveal how definitions arrive.

Category-oriented routines traverse stored trees and increment/decrement linked-node counters (`00c386b0`, `00c38750`, `00c37e70`, `00c37ec0`). Generic tree rotations and repair routines support insertion/removal (`00c39210`, `00c39260`, `00c393b0`, `00c39470`). Predicate-based relinking is guarded to run once (`00c38ae0`); its predicate at `00c34ee0` is outside this shard and remains unidentified.
