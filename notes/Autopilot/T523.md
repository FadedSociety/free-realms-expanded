## Threat note (secure-code-guardian)

The file is server content, not client input. No packet reaches the loader, and nothing loads this
file at runtime yet. The generator reads pinned lab references; it refuses to write if a type's
model/effect/cursor is absent from the client resources, a drop item is absent from Legacy's item
table, a pool names an unknown type, or a kept pool has no spawn file. A corrupt or hostile
content file is still bounded by `HarvestNodesContent::load_from` (1 MiB, serde) and would be
ignored by the runtime while dormant. When collection-node-pickups wires it, it must keep the
existing `add_sites` sanity bounds (interact range 1..=50, respawn 1..=86,400, finite positions,
unique spawn ids), use the new guid tag 3, and grant drops only from server-owned tables, never from
a client-reported pick. No player state, coins or items are touched or persisted here.
