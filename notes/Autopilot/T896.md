## Finding the brief did not state

None of the 33 rows has a model id or a locale name id, and `world.rs` sends `model_id.unwrap_or(0)` and
`name_string_id.unwrap_or(0)`. A loader that only admitted `video_index` would spawn 33 actors with model 0 and no
nameplate (the same "no model, so nothing drew her" class as T299/T331). So the loader rule has two parts: a confidence
floor, and a body (a model and a name id). Only one of the 33 has a body the client names: Cudip
(`Models.txt` row 2044 `fairy_m_cudip.adr`, locale id 426988 = "Cudip"). The other rows keep their video position and wait
for a model: they are stored truth, exactly like T878's twelve.
