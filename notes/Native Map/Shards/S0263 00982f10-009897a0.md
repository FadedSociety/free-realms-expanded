## Classes and subsystems

- `00982f10` loads character-creation tables and related account/server data. RTTI-backed `HashListMap`/`HashList` methods at `00983290`–`009836c0` manage customization and name-wheel containers.
- `009836e0` constructs `CharacterCreationManager` and initializes its member containers. The 24-bucket strong-GUID map operations at `00983a70`–`00985110` link, search, and remove GUID-pair nodes. `00985200` and `009852a0` register/unregister pairs and refresh the client `BaseClient.Bosses` data source. These are client display updates, not evidence of original server rules.
- `00984fe0` initializes node-index fields and a 24-bucket GUID map; the owner has no RTTI class name in this function. `00985340` is a shared actor-node constructor-on-miss used by AddNpc, mannequin, and pet-target callers. It appends successful nodes to a primary 100-bucket list and a second 100-bucket index (header `manager+0x1a0`, count `+0x1a4`, buckets `+0x1a8`). The `Stage7 NPC Grounding Semantics.md` note cites the AddNpc chain `0092f460 → 00985340 → 00968c80` and its position arguments; that caller-specific evidence does not define the shared routine's only use or resolve stationary-spawn grounding.
- `00985550` receives a manager in ECX and node on the stack, removes the node from both indexes, conditionally obtains an 8-byte output through the subobject at `node+0x54`, passes the two dwords to `009852a0`, and calls the node's primary deleting slot with argument 1. The tested bit is bit 1 of `node+0x141`; its meaning is unknown. `00985600` similarly rebuilds list indexes and conditionally calls `00985200` with a GUID pair.
- `00985790`–`00985ed0` include RTTI-backed `ControllerDressingRoom`. `00985ce0` maps event IDs `0x4a`–`0x4f` to flag bytes. `00985a10` stores float4/matrix blend state and calls transform helpers; its controller association comes from related constructor/update code, not its own RTTI.
- `009860e0`–`00987730` contain SoeUtil hash/list operations and local command registries. `00986c10` checks the secondary 128-bucket index only when the key is absent from the primary 1024-bucket index. `009874e0` copies prefix matches into a temporary array through `00987310`, tokenizes the input, and appends tokens through `00987250`; it does not unlink source entries. This is local command processing, not wire handling.
- `00987820`–`009884f0` provide hash-map constructors, cleanup loops, allocators, and deleting destructors. RTTI names identify pending-image and integer/string maps. `00989030` completes a pending image load; `00989470`/`009894d0` construct and destroy `ImageAsset2`; `00989540` obtains an asset name through its virtual interface and passes the incoming bytes to Scaleform's `UpdateImageBits` callback.

- `00987800` is a split-word integer add; its enclosing type and semantic field are unknown.
