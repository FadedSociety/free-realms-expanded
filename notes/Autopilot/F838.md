## Threat note (secure-code-guardian)
The leave request carries no payload, so no new client field reaches the server. A hostile client can only
leave its own session's visit; the 35/3 guid is derived from the server-minted fixture guid (bit 55, which
`mint_fixture_guid` keeps clear), never copied from a packet, so it cannot name another player's actor. A
repeated leave is refused by `NotInHouse` before any reply, and the refusal changes nothing. The removal list
is read from the lot this session entered, bounded by `MAX_STATE_FIXTURES`; the 35/3 body carries no client
data, and the path touches no file, item, coin, reward or role. The leave removal timing/order is
reconstructed (R); the bytes are the captured pickup shape.
