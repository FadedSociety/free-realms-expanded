# S0347 findings: pet data and packet helpers

## Observed

- `00b561d0` constructs `PetMoodListPacket` through pet base subtype `0x22`; `00b56240` clears its list fields and restores `BasePacket`, while `00b562c0` is its scalar deleting destructor. These are RTTI-backed packet class identifications.
- `00b562e0` reads `%sPetEffects.txt`, skips comment rows and writes parsed values at handler offsets `+0x12b0` and `+0x12b4`. `00b5aa40` reads `%sPetNames.txt`, parses bracketed keys, maintains a sorted 0x24-byte two-string record array, and stores a separate default value. `00b5ae90` supplies `Resources/` to that loader.
- `00b589c0` decrements a pet timer in milliseconds and compares minute buckets at 60,000 ms before emitting `PetsHandler:PetExpireTime`. `00b58bd0` stores a pet identifier pair and emits `PetsHandler:PetIsActive` through a Lua parameter array.
- `00b596f0` initializes Lua-facing `BaseClient.PetList` and `BaseClient.PetActive` data sources, pet arrays, and related handler objects. `00b59b90` releases those arrays, nodes, and references during teardown.
- `00b5b120`, `00b5b210`, and `00b5b340` install RTTI vtables for `BasePetTrickDataSource`, `PetTricksDataSource`, and `PetTricksEquippedDataSource`. The latter two derive from the base source in their constructors. Their slot-zero deletion entries are `00b5b1b0`, `00b5b2e0`, and `00b5b410`.
- `00b56dd0` and `00b57170` resolve record/model data and pass transforms and strings to actor-creation code. Calls from pet handler paths connect them to pet actors, but the exact actor type and creation flags remain unknown. `00b564d0` draws sampled path data using `aoe_ring.dds`, `R_WRIST`, and `arrow_click-to-move_left.dds`.
- `00b595d0` writes two bytes from object offset `+4` and one byte from `+8` into a bounded output buffer. `00b5a240-00b5a8d0` and `00b5b0c0` call this shared prefix writer and append fixed fields. `00b5a530` specifically writes the 16-byte block at `+0x10` and byte at `+0x20`; Research/Pieces/091 identifies it as `PetCanGoLocationPacket` subtype 26.
- The checked readers `00b57c70-00b58450`, plus `00b5a130` and `00b5a1b0`, call fixed-field readers, then enforce a failure flag and the caller's trailing-byte policy. Their direct caller is the shared Pet handler `00b5ce60`.
