# T475 - Housing 127/45: head size 10, and the instance record's snapshot string after factory_plot_id

## What changed

- `src/housing_native.rs`
  - `ZoneData.unknown_word` is now `head_size_tenths`, documented from `0x00ab6c80`, `0x00ab07a0`
    and `0x00ac36c0`/`0x00ab96e0`. `flag_a`/`flag_b` keep their names. The struct doc now says
    +12 goes to `Housing:SetIsInInstance` as its second argument (`0x00ab94b0`), which the Lua
    preview handler names `isPreview` (R), and that +13's meaning is unknown (R).
  - `PlayerHousingInstanceInfo.unknown21` is now `directory_snapshot` (meaning (R), community
    evidence). It moved after `factory_plot_id` in the struct, `encode` and `decode`. The struct
    doc lists the full client order.
- `src/housing_service.rs`: new const `HOUSE_HEAD_SIZE_TENTHS: i32 = 10` (the client's own
  constructor default, so a const and not a tuning value; the doc gives the about 1..60 range in
  case it is ever made tunable). `zone_data` sends it. `instance_info` sends an empty
  `directory_snapshot`, the same as before.
- Effect on the wire: 127/45 bytes 6..10 change from `0` to `10`. Every other byte stays the
  same today, because the server sends an empty snapshot and factory_plot_id 0, and the old and
  new order give identical bytes for those values. The order fix is latent until real lots or
  the directory fill those fields.

## Client evidence (IDA, re-checked 2026-10-22)

- `0x00ab07a0` (127/45 constructor): `sub_AA4990(45)`, then +12 = 0, +13 = 0, dword +16 = 10.
- `0x00ab6c80` (127/45 reader): bool +12, bool +13, i32 +16, then `sub_AAFE10(this + 24)`.
- `0x00ac36c0` (127/45 handler): builds through `0x00ab07a0`, reads through `0x00ab6c80`,
  refuses on the overrun flag or leftover bytes, then `sub_AB94B0(1, +12)` and
  `sub_AB96E0(+16, 1)`.
- `0x00ab96e0`: flag 1 selects `"CuteMode:SetSizeInstant"`; the argument is `(double)word * 0.1`.
- `0x00ab94b0`: stores +0x14 = a2, +0x15 = a2 && a3, then calls Lua `Housing:SetIsInInstance`.
- `ScriptsBase.lua:12082-12146`: `CuteMode.value = 1`; `SetSizeInstant` sets value and calls
  `Ui.SetHeadSize(self.value)`. `Inflate` tops out at 5.2 (3.2, then +2 while under 5).
  `:20189` HousingPreviewHandler `SetIsInInstance(self, inInstance, isPreview)`.
- `0x00aafe10` (instance record reader), confirmed field by field: u64 +0, u64 +8, i32 +16,
  str, str, i32 +52, i32 +56, 8 bytes +64, i32 +60, bools +72/+73/+74, str, str, f32 +124 (dword
  31), i32 +128 (dword 32), bool +132, bool +133, i32 +136 (dword 34), str, then
  `sub_8CB4C0(this + 36)`. `0x008cb4c0` reads 8 bytes.
- Community cross-check only, no code taken (AGPL): Lxzxrus-Free-Realms-Server@37ef175 writes the
  snapshot after FactoryPlotId and sends HeadSize 10. That repo names the +12 bool `CanEdit` and
  says Decorate needs it true. The client Lua names the second argument `isPreview`. The brief
  says Decorate already shows natively with false, so it stays false here. The lead's native run
  should confirm Decorate still shows.
