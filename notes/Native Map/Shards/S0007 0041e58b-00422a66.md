## Main findings

- **GFC control layout and input.** `0041eea4` reads four stored margins through the `GRectMargin` conversion at `0041edd1`; `0041ef78` measures child extents and adds margins. `0041e58b` has keyed early exits: two keys return virtual slots `+0x24`/`+0x28`, and other cases return handled without geometry. The key identities are unresolved. `0042050b` translates selected children but recursively visits every child whose bit `0x10000` is clear; its recursion filter is broader than its translation filter. `00422a66` handles the keyed/drag path and reuses geometry emit helpers.
- **Internal pointer dispatch.** `00421a20` walks child controls and returns a hit target. `00421d2d` updates the hover target at `+0x160`. `004206c2`, `00420c75`, `0042280f`, and `00422996` build local event records and dispatch through virtual slot `+0x110`; the records test mask `0x24924`. `004206c2` first calls the owner-slot attach operation `0040f97f(0)`, passes seven stack arguments to slot `+0x274`, and gates the other object's `+0x278` fallback on a non-null object with flag `0x800`.
