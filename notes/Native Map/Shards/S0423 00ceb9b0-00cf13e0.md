## Classes and systems

- `ClientAreaAmbientSoundProperty` (`00ceb9b0`, `00cebd20`, `00cebd80`, `00cebdc0`) loads `TrackId`, `SoundDefinitionId`, `FinishPlaying`, `RetriggerDelay`, and floor tolerance, then starts/stops area sound through shared sound-definition references (`00ceba60`, `00cebba0`, `00cebc60`). This is `asset.definition` data driving `audio.definition` behavior.
- `ClientAreaCompositeEffectProperty` (`00cebe50..00cece40`) reads/writes effect IDs, transforms, offsets, scale, floor tolerance, and `Broadcast`; acquires/releases typed resource references; composes transforms; and updates effect targets. `00cece40` queues a local effect and, when broadcast is configured, constructs `PacketUpdateClientAreaCompositeEffect` and may wrap it in a tunneled packet (`00cecd10`). The code shown builds objects but does not show the send call.
- `ClientAreaRandomEffectProperty` (`00ced1f0..00ced510`) carries distance/frequency bounds and placement flags (`OnlyPlaceInFrontOfCamera`, `PlaceOnGround`, `RandomizeY`, `AreaRelative`), plus rotations and scale. `00ced210` copies the active area transform to the effect updater.
- `ClientAreaCombatMusicProperty` (`00ced770..00ced860`) stores a sound-definition ID and selects or clears the global combat-music state. `ClientAreaMinimapProperty` (`00ced8d0..00ced990`) serializes enter/exit map names and both hooks tail-jump to `MiniMapResetHandler`; their bodies load different owner fields but otherwise share the handler. `ClientAreaSkyTransitionProperty` (`00ceda00..00cee120`) supplies the `SkyTransition` type name and hashes the property string.
- Broker functions divide between `net.packet.broker` parsing (`00cf0180..00cf0590`) and `ui.broker` data sources (`00cee3a0..00cefe40`, `00cef480`, `00cefb90`). The UI data-source tree exposes `SearchItems`, `MyItems`, and `PlayerInventoryItems`; its row sources filter and format inventory/listing fields.
- `ui.coinstore` data sources (`00cf0700..00cf1280`) cover coin-store items, search results, player selling, active filters, and transaction-history field names. Several ref-count assignments and cleanup bodies in the range are generic `engine.refptr` helpers; list routines are mechanical `engine.containers` operations.
