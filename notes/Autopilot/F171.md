## Security threat note (secure-code-guardian)

A hostile client can forge family 138, replay register/cast/reel, skip lifecycle
steps, send malformed handles or a foreign actor, and cannot name a fish, amount,
item or outcome: the server-owned fishing service validates session ownership,
order, handle, phase and server timestamps. This task is test-only and adds no
parser, selector, id or reward source. The refusal regression still drives the
production `handle_fishing` path, snapshots inventory, coins, complete profile
state and active job, and asserts they are unchanged after the missing-profile
error; that test fails when production adoption is disabled (canary below).
