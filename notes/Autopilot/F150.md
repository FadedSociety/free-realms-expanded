# F150 Refuse a reloaded field enemy that reuses a battle-spawner GUID

  `FieldBattle::spawner.guid` to its taken-GUID set, alongside world enemies

## Security threat note

A hostile client cannot call `load_field_enemies` directly: the two production
routes are the startup content load and the developer `realm reload enemies`
command, which is gated by developer tools and admin role. The loader reads a
server file, caps it at 128 KiB and its record counts, validates every actor
and GUID, and returns `Err` before replacing `self.field`. A refusal consumes no menu, offer, item, coin or
cooldown and writes no save. This change adds one check to that existing
validation path; it does not add a selector, so no `app_fuzz` seed is required.
