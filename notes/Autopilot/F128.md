## Threat Note

- A hostile client can send 26/10 for an unknown NPC, a closed menu, or an
  option id that was not offered. `NpcInteraction::select` checks range, the
  active NPC and the exact offered option before returning an action; the
  invalid-choice regression asserts the whole gateway snapshot is unchanged.
- A forged 26/6 choice without a pending quest choice is ignored and closes the
  dialogue; it cannot manufacture a 49/1 offer or an end screen.
- 49/2 only accepts the server's pending offer. 49/14 only settles a persisted
  `pending_turnin` and uses the server reward grant key. Replaying 49/14 after
  completion changes nothing and pays nothing; this is asserted after reconnect.
- The race option appears only when `kart_entry.json` contains a complete race
  and the NPC is listed in `kart_gates.json`. `KartGateway::admit` additionally
  checks already-active, busy and cooldown state.
