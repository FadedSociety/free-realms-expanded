   ride in `wallet.earned_rides` only when it settles: the ride is owned (SC equivalent, as before)

   `data/content/sc_rewards.json`). A refused game returns `Earned::default()` before touching the
   wallet: no chess SC and no daily bonus, and the daily-bonus day is not consumed.

   transaction carries a Station Cash wallet (`next.wallet.is_some()`, staged only by

   The suppression is not widened to wallet-less grants: achievement item grants (blank display,
   no rows) still send their bundle, and `empty_bundle_is_69_byte_reader_body...` still pins it.

## Security threat note

A hostile client cannot choose any input: the win/draw flag and ply count come from the server's
own chess table at settlement, the ride decision from server inventory, and amounts from data. A
repeated settlement is stopped by the table's `settled` set, so a replay changes nothing. A refused
chess game returns before the wallet clone is adopted, so it consumes no daily bonus and no day.
`chess_min_plies` is bounded at load (0..=400), so a bad data edit is refused instead of loaded. A full bag cannot be used to force-settle the ride: the unsettled ride is
never recorded, so it can only be granted once with room.
