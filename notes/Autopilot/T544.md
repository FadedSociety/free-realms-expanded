## Threat note (secure-code-guardian)

A hostile client can send 26/8 with any target, from any position, and 26/10 choices it
was never offered. This slice changes which static NPC rows are drawn and their client
name ids; it adds no parser, no packet field and no new handler. The click still resolves
only through the regional row by actor id and `check_range` (12 m, same zone); an unknown
or far target is refused before anything is consumed, and the new suite's real Talk
assertion confirms the state is unchanged. The removed extras rows are server-side
content: a client cannot choose a different row than the actor id names. No name, chat
text or client-supplied string is written to content. The name id is a client locale
pointer, so a wrong value would only blank a nameplate, never grant anything.
