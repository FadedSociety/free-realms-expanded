## Conflicts

1. **Head-slot item names.** The wiki wheel lists "Saved by the Bell Brawler Cap", "Stable Condition Medic Cap" and "Novice Wizard Fez". The client has no such items. It has "Saved by the Bell Brawler Bandana", "Stable Condition Medic Beanie" and "Novice Wizard Cap". The client names are used above.
2. **Bonus item name.** Video reads "Saved by the Bell Brawler Cleaves". The client set has Gloves, Boots, Pants, Shirt, Shoulderpads and Bandana, no "Cleaves". Treated as a misread of Gloves.
3. **Members-only coin figure.** The client locale has "Bonus: N Coins!" strings for some values (for example 88, 77, 281) but none for 126, so the wiki's 126 is not client-confirmed.
