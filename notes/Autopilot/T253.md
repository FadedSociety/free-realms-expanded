## Security note (secure-code-guardian)

Attack surface: a hostile client can send, while a movie is live, a truncated or extended
26/42, arbitrary 39/x frames, the five blocked families, `realm exit`, or other chat.

- Wrong-length 26/42 and malformed 39/x return the same `Err` as before; the caller
  stages `handle_opening_inner` on a clone and drops it on `Err`, so the run, clock,
  inventory and opening state are untouched (asserted on `GameplayState`).
- Blocked families and other `realm ` text answer with the same fixed system strings and
  change nothing (asserted).
- `realm exit` cancels only through the engine's `cancel()` + applier; a cancel outcome
  carries no transaction, and the matrix asserts the inventory is unchanged, so a client
  cannot use Close/exit to earn.
- No new `unwrap` on client data: the arms unwrap the engine `Option` only after
  `running_movie()` proved it occupied; lengths are checked before any parse.
- No new packet, selector, save field or trace field is written.
