## Security threat note (secure-code-guardian)

A hostile client can send forged target names, arbitrary or replayed invitation
generations, malformed or truncated 40/4 bodies, repeated accepts/declines, a
response to an expired pop-up, and out-of-range lifetime configuration.

- Names are bounded and resolved through the authenticated identity directory;
  the actor guid comes from the session, never the packet sender guid.
- A response must match the current server-owned pending invitation's fresh
  per-invitation generation. A stale pop-up, repeated response or forged value
  receives 40/5 code 3 without consuming the replacement invitation, including
  the same-leader/same-target/same-group re-invite case where the group id is
  unchanged (F189; the earlier group-id check missed that case).
- Malformed bodies are dropped by the existing bounded parser; no
  client-controlled length or value is indexed.
- The lifetime is parsed as `u64` and rejected outside 1,000..=600,000 ms
  before sessions are accepted.
- Every tested refusal leaves membership, group mappings, profiles,
  persistence, capacity, the prior configuration and the replacement invitation
  unchanged.
