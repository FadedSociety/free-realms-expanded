## Security decision (secure-code-guardian)

Threat: a client can send `realm reload ...` (a 15/1 chat line) without the
rights to change live content, and a malformed or missing content file can fail
halfway through the ordered loaders. Existing gates still require the builder
or admin role plus dev tools, and the server reads only its configured
`content_dir`, never a client path. The staged `Gameplay` clone means a hostile
or broken file cannot publish an earlier loader's abilities, behaviours,
activities, visibility or packets; a refused request returns the normal error
reply and changes nothing. The regression sends the real chat packet through
`handle_in_world` and asserts the refusal leaves the shared field, behaviours,
job bar and queued replies untouched. No new input is parsed into a save, item,
coin, reward or role.
