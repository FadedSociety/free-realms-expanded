## World loading and shutdown

`009386f0` resets zone/position state and applies the destination transform. When `this+0x8f` is zero it calls `00936d00(1)`; when nonzero it bypasses that wait, loads `Sky.xml` through `006f9e60`, calls a sky-state helper, and marks the branch successful. It later clears loading fields and logs the zone result. The `WaitForWorldReady` loop at `00936d00` checks zone readiness, proxied character/actor availability, actor draw readiness, sky setup, and minigame processors (race, derby, soccer, battlemages, fishing, ship combat). It reports stalled states and gateway disconnects, coordinates loading events and timers, logs the final location, and sends PacketClientFinishedLoading on the zoning-completion path. This is the clearest evidence in this shard for a client loading barrier; no corresponding server-side state machine is recovered here.

`009359e0` is shared by BaseClient and PlayClient. It logs shutdown, invokes manager and GUI-save cleanup, destroys owned objects, clears pointers, and frees the last allocation. A cited review note assigns `0093695c` (`mov [esi+0x77c], ebx`) to this teardown, but that address lies outside `009359e0` (426 bytes, ending near `00935b8a`); it cannot support the claimed field clear. The actual owner of that write remains to be reconciled with the note.
