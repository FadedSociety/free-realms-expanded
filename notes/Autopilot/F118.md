# F118: repair T018 review blockers

## Changes

- Reviewed `lab/autopilot/reviews/0dab5e2-T018.md`. Both findings were valid.
- `26/24` recipe admission now checks `Gameplay::activity_busy()` before
  ingredient, station or service work. An active Mining or Harvesting run
  therefore cannot start a simultaneous Cooking, Smelting or Forging movie.
  A refusal sends the existing Busy chat line and does not mark the gateway
  state or gameplay dirty.
- `Gameplay` now stores the world station model rules instead of a startup
  snapshot of resolved station coordinates. `crafting_stations()` derives the
  current set from opening actors plus `NpcVisibility::model_actors()` at every
  start and completion check. Placement moves and removals therefore update
  both the `26/24` admission and the Completion checks.
- Added a gateway regression that starts a Copper Vein run, moves with valid
  125 poses to a real forge, and sends `26/24` for Copper Bar. The request
  refuses with unchanged snapshot and both gateway save flags false.
- Added live-world station regressions for moving and removing a placed forge.
  Each covers start at the old/new coordinates and completion at the old
  coordinates.

## Reconstructed rules

- (R) Recipe-start busy policy uses the existing shared activity admission
