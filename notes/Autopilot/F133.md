## Security note

A hostile client can send any runtime actor id, menu choice, quest id or
attack target. The NPC path resolves only server-authored actor bindings,
rejects unknown runtime ids and unoffered choices, and verifies zone and
distance before opening or consuming a menu. Quest ids must match a pending
server offer or turn-in. Kill progress is forwarded only from
`EncounterOutcome::defeated` after server-side damage; no client-reported
impact advances it. Reward application remains the existing idempotent
`quest:<character>:<quest>` grant, and the failed-choice test snapshots the
save and asserts no change.
