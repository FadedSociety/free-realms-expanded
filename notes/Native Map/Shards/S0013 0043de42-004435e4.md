# S0013 findings

## Framework and platform connections

- GFC class plumbing covers `GuiApp`, `GFormCtrl`, `GVBoxLayout`, `GHBoxLayout`, `CtrlManager`, and `GMessageTargetList`. `0043EDC1` is `GFormCtrl::ProcessControlMessage`; it dispatches message IDs from `param_2+0x1C` through control virtual slots and helper calls, returning 1 for handled IDs and 0 otherwise. It is also present in the `GuiFreeLayout`, `GuiVLayout`, and `GuiHLayout` slot-70 tables. `0043FF6F` tests whether the circular target list is nonempty.
- `GuiApp` initialization (`0043EB16`, `0043EBC0`, `0043EC67`, `0043FCFB`) connects stored/default dimensions to control-manager setup. `0043F98D` scans 16-byte display rectangles, tracks maximum width and height, halves dimensions above 800x600, and submits a descriptor to `0043D9CD`; `0043FCFB` retries using defaults when setup fails. `0043E0C7` applies popup styles and extent properties through the embedded object at `window+0x24`.
- Win32 support dynamically resolves USER32 multimonitor functions (`00440569`) and wraps their monitor/display calls (`0044065E..00440931`). Window support includes A/W default-procedure dispatch, window state and geometry helpers, and the message pump (`00442335`), which checks the installed filter for IME and selected input messages before translation/dispatch. Input support maps Windows keys to/from keysyms and handles IME composition/candidate operations (`00441F59..004420D3`). Clipboard support registers the Win32 implementation and resolves format names (`00440F13`, `00440F73`, `004435E4`).
- Nine small helpers call pooled allocator `004D9207`, write the fixed heap-tag pair into the returned block at class-specific offsets, and return the block or null. They are allocation/tagging helpers, not object lookups: `00440330`, `00440AA5`, `00440EA1`, `004410CF`, `00442154`, `00442290`, `004425BB`, `00443427`, `00443572`.

## Cross-function behavior and limits

No function in this shard builds, sends, parses, or dispatches a network packet. All `wire` fields are empty, so this slice supports no original-server contract inference.
