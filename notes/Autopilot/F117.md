## Security note

A hostile client can send foreign keys, absent or stale poses, distant contacts, non-finite or
excessive impacts, malformed or stale quit records, early/replayed close records, and repeated gate
selections. Each path is validated before the staged Derby state or reward state is committed. The
contact reporter is the authenticated sender, the target must be a server-owned participant, and
the match instance comes from the server.
