## Code families and subsystems

Most of the range is instantiated MSVC STL code (crt.stl): red-black tree insert/erase, range erase, vector storage/insertion/copy helpers, plus exception and argument-forwarding glue. The map erase bodies throw the literal "invalid map/set<T> iterator"; 0046f4e0 throws "vector<T> too long".

The tree bodies use two observed node layouts: colour/isnil at +0x10/+0x11 and at +0x14/+0x15. Their common exception text and erase shape identify both as map/set-style trees, but do not explain why the layouts differ.
