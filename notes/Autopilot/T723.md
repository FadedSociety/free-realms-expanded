## Threat note (secure-code-guardian)

A hostile client can send 49/2 for a quest it was never offered, while another job is active or before a prerequisite is done, 49/14 early or twice,
movement or `realm` text to fake a rank, or a 49/15 Start quest with a forged id. All go through the unchanged `QuestEngine` gates
(`offer_denial`, `begin_ready_turnin`, `finish_turnin` idempotency); the rank goal reads the server's own `Profiles::rank`; `realm level` needs
dev tools and an Admin role (the test enables both on the server side). The 49/15 for the disabled 3130001 is refused with one chat line
and no state change; the tests assert each refusal leaves the serialized save byte-equal and that the refused postman start grants no
coins and unlocks no profile.
