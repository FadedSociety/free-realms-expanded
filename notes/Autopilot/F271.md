## Security threat note (secure-code-guardian)

- Hostile input on this path is the existing 26/8 target GUID and the 26/10
  NPC GUID/option pair. The router resolves the target through
  `content_npc_key`, requires an open menu for that exact NPC, and refuses an
  unknown or out-of-list choice with `InvalidOption` before any mutation. The
  new test sends `i32::MAX` and then proves the same open menu still selects
  Talk; the canary proves the assertion would catch menu consumption.
- No greeting id comes from client bytes: it is a `u32` read from server
  content. The F271 content change only adds static evidence rows; the client
  cannot inject locale text, choose an id, or drive an allocation size. No
  save, inventory, coins, rewards, roles, chat or trade state is touched, and
  the loader bounds (8 MiB/file, 32 MiB total, 20,000 rows) are unchanged.
