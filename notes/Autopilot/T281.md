  pass the 12 m range and zone check, and select an option from the open server

  49/14 must match `pending_turnin`, set only by a server Talk that completed

  content row through the existing per-character grant key. Wrong NPC,
  out-of-range, wrong-zone, forged accept/turn-in and replay tests snapshot the
  full `GameplayState` **and** its serialized save bytes and assert equality

- **Economy:** 50 coins/25 Adventurer XP once, no items, no client quantity or
  item id. The near-cap test proves an over-cap grant refuses atomically for
  that player only while the other player completes and is paid.
- **Fail-closed content:** the split loader rejects a 0.0-radius objective with
  `InvalidData` before any player state exists; no `unwrap` on client data was

  first; a future original quest authored on Jacque would need the lead's

  `pending_turnin`, 49/14 is paid without rechecking the speaker or position
