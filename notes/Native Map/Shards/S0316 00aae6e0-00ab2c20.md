## Housing editor and placement

00ab0a80 switches edit mode, clears preview state, creates or releases actor/tile/player handlers, and invokes the Housing options at 00aaf090 and 00aaf1b0. The option handlers apply UseFreeFlyCamera and UseAutoOrientation. Selection callbacks 00ab0d60 and 00ab2250 resolve a two-word selection key, set distinct modes, and save transform data. 00ab1e30 builds preview rotation using the recorded 15-degree step and a conditional 90-degree path. 00aae6e0, 00ab1380, and 00ab0f20 query geometry and adjust/filter preview transforms; 00aaed30 is a shared transformed-bounds test also called from player-position handlers.

This refines Research/Pieces/027 Housing fixtures and limits.md, which reports collision as unrecovered: this shard contains client-side convex-hit queries and candidate filtering. The exact acceptance semantics of hit types, the +0x128 orientation flag, and runtime placement behavior remain open. Static collision code does not prove successful native placement or the server's rule.

These agree with the field order recorded in Research/Housing Fixture Tail Compatibility.md. 00aafe10 is shared by the HousingPacketZoneData body reader and HousingPacketInstanceList entry loop; 00aafb50 rebuilds a counted linked list for HousingPacketFixtureItemList.

The shard also contains packet cleanup functions for housing customization, fixture update/asset, save, placement-denied, and notification packets, plus rating-packet deleting destructors (00ab0500 and 00ab0980–00ab0a20). These destructors do not establish send or receive direction.
