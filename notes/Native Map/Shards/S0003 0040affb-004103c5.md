# S0003 (0040affb..004103c5) - display-control, effects and MSVC-toolchain code

Shard inventory: 220 functions. MSVC VS2005 toolchain/STL/CRT emissions dominate (~130 records),
the rest is the client's display system: the GCtrl control family, effect classes
(GLineFx/GFillFx/GBlitFx), GFC tagged-value and string plumbing, and geometry helpers.
**No function in this shard builds, parses or dispatches a packet** - every `wire` array is empty
and every `server_inference` is null. Nothing here constrains the original server.

This file reflects the repair pass after independent review. Disputed addresses were re-read from
pseudocode and raw bytes; the notes below record corrections and remaining limits.

## The GFC tagged-value record (the shard's central data type)

A 30-byte stack record: tag word at +0 (six 3-bit slot tags, mask 0x24924 = slot type 4, i.e. the
slot holds an interface released through vtable slot +0x10), six slot dwords at +4..+0x18, 2-byte
trailer at +0x1c. Built by 0040e04e (tag 0), 0040e081 (tag 4 + AddRef), 0040e110 (tag 0x22) and
mutated by 0040e164 (16-bit slot write, tag 2). Consumed on the stack by 0040e51f and 0040e5b0
(two-record operations with selectors 0x4400000 / 0xc400000 through the helper pair
00409c73/00521c31), and by the query functions 0040ec5d, 0040ecc6, 0040f2a5, 0040f40e, 0040f97f,
0040fa82, 0040ff13; every consumer re-tests the 0x24924 mask and runs the cleanup FUN_004d93a3,
which is the reliable fingerprint of the type.
