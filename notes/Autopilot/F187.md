## Security decision (secure-code-guardian)

Threat: any client can send `realm reload ...` as a 15/1 chat line, and a
hostile or malformed content file can fail halfway through the ordered loaders.
Unchanged controls: the builder/admin role plus dev-tools gate remains the only
entry (`developer_cheat`), the server reads only its configured `content_dir`,
never a client path or quantity. The staged `Gameplay` clone plus the all-or-
nothing commit (still only `abilities`, `encounter`, `activities`,
`npc_visibility`) means a refusal publishes neither state nor reload-generated
packets. This task moves the staged `Outcome` merge into `Outcome::absorb` with
identical semantics; no new input is parsed and no save, item, coin, reward or
role is touched. The protected regression asserts the refusal leaves replies,
`changed`, shared actors/order, behaviour, the job bar and activation packets
unchanged.
