  active in a pack with no class content: the packet is routed through
  `Gameplay::handle_in_world`; the no-opening dispatcher leaves it inert, and
  the opening route refuses before building `recipe_book::Player`. The new
  test asserts the full `GameplayState` is unchanged and the chess table still
  accepts a legal move, so neither a menu, an offer, a cooldown nor an item is
  consumed.
- Hostile client cannot choose chess moves or replay a win: unchanged from
  F152/F140; `ChessService::settle` remains the only grant site, gated by a
  server-verified checkmate plus the client acknowledgement. This task does
  not touch it.
- Operator content is the only source of chess tuning. A missing or partial
  `scoring` block, an out-of-bounds value, or a malformed row now fails content
  load; `ChessTables::set_scoring` re-validates before installing a block.
- No auth, session, transport, trade, studio or role code is touched; no new
  client input is parsed.
