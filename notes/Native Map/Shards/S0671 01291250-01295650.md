## Evidence boundaries and corrections

The integer result branches and dialog names describe client behavior only. They do not establish original server reply names, meanings, or state transitions. No packet dispatch or delivery is visible in these UI methods, and no server inference is made.

Rechecked the prior disputed records against pseudocode and raw epilogues. All 11 bodies set EAX to 1; the four Ghidra void declarations at 01291c70, 012928f0, 01293230 and 01293e90 obscured that return. At 012928f0, code 0 with arg 5 false bypasses success handling without showing the error dialog; only nonzero code selects the error dialog. The earlier shard draft also grouped 01295090 with ignore-list refreshes; it opens FriendsList instead.

At 01294c60 the entry ECX is replaced from a stack argument before 012eb250, so the slot calling convention is unresolved. Its constructor receiver is the local command object in ECX; the GS-cookie expression in decompiler output is not a constructor argument.
