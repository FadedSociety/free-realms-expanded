### Why the "build it from data/content" alternative was not used

The review offered "build the gateway from `data/content` with the `with_launch` loader". A probe
(scratch test, deleted before finishing) showed that cannot work on the public tree:
`Gameplay::load` needs `inventory.json`, `categories.json`, `combat.json` + its template and
`quests.json` from the private package, and it refuses `mining.json`/`harvesting.json`/`smelting.json`
without the opening campaign. Synthesizing those would duplicate private fixtures and invent quest
and combat content, which Ponytail and the content rules forbid. The env override + documented skip
is the alternative the review itself named as acceptable.

## Threat note (secure-code-guardian)

Touched code parses client input: the listener reads TCP frames (414/411/ping/unknown) and the card
run reads 39/x and 26/42. A hostile client can send any class id, instance, group/game, packet
length, ticket text and character id, and can mix children in one `[0, 25]` datagram. Refusals and
why they hold:

- The listener answers only the classes it decodes; each answered kind and unhandled commands have
  their own 16-line per-connection budget, checked before any event is built; a malformed frame or
  oversize frame closes only that connection. Login still needs the live session that minted the
  one-time launch ticket (T764/T805 code untouched), so no new credential path exists.
- The card run accepts only packets naming its own current/last instance; the results Close is
  accepted only in the terminal state and retires exactly once; a malformed 39/x is a per-message
  `Err`, and in a combined datagram the bundle is refused before the staged clone commits (game
  state unchanged, only the sender's session ends).
- Events carry typed values only (peer address, class id, guid, fixed reason word): no ticket,
  session id, user name or client text, so a client cannot forge a log line or leak a secret.
- No new timeouts, caps or economy values; the listener caps remain log hygiene (R). No hidden
  side table or shared state is added.
