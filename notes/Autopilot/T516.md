## Security threat note (secure-code-guardian)

This change adds no parser or handler. The only client-reachable path it affects is housing entry
(127/19) and deed purchase: a hostile client can send any `house_guid` and any listed deed id.
Entry stays gated by `Housing::can_visit` (owner/permission) and then by the row's `enabled` +
non-null `scene`; a closed row (33/34) is refused with `HouseSceneUnavailable` **before** any
session or persisted mutation, asserted byte-for-byte in
`a_saved_disabled_farm_lot_loads_and_entry_changes_nothing`. Deed grant still requires an enabled
lot, refuses the starter and already-owned lots, and charges through the existing staged order
path. Scene/sky strings are server data from the bundled table, not client input; the loader keeps
its 256-byte / finite-value checks. No saves, coins, items or rewards are added or changed, so no
new economy or injection surface exists.
