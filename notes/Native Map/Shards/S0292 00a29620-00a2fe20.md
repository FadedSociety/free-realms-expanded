  virtual method of the processor.

  `0089adc0`, then pass it to the gateway send path `00925640`; the cookie-looking pseudocode
  argument at the constructor call is not a real argument.
- (review) The scalar-deleting destructors of the concrete packet classes sit at slot 0 of each
  class vtable, not in the shared base class's: 01813880 -> `00a29c80`, 01813888 -> `00a29d50`,
  01813890 -> `00a29e20`, 01813898 -> `00a29ef0`, 018138a0 -> `00a29fc0`, 018138a8 -> `00a2a090`,

  layouts are known only at the field-offset level. In particular, `00a2a910` consumes three

  the third writes +0x18/+0x1c. It then reads dwords +0x20/+0x24/+0x28, bytes +0x2c/+0x2d,

   into dispatcher `00a35cc0`.

   are unowned; a neighbouring shard must identify their classes.
6. The concrete-class scalar-deleting destructors are labelled `likely`, not `confirmed`, because
   their class comes from a vtable slot outside the function body.
