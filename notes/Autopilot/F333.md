## Threat note (secure-code-guardian)

Attack surface exercised by the changed tests: any client can send 26/8 with an arbitrary
target from any position, or 49/14 with any quest id at any time. No production parsing
changed in F333.

- The 26/8 from a far position is refused by the existing range gate and asserted to change
  neither session; A's pending offer is untouched.
- 49/14 settles only the server-saved `pending_turnin` with a server-opened end screen. The
  forged reply in A's session is a clean no-op (serialized bytes equal); B's held end screen
  remains pending and pays only through B's own reply. Canary 1 shows the test fails if that
  guard is removed.
- The model gate is a content-integrity check, not a trust boundary: it prevents a wrong
  `model_id` from shipping a different or missing body while the file name looks valid.
- No client amount, item id, model id, quest id or result is trusted by the changed code;
  there is no new reward, save or broadcast path.
