spawn id, type or reward, and nothing from the client reaches `node_guid` or `add_sites`. The
guid tag is server content: a reused tag could only collide two server-authored spawns, which made
`GatheringNodes::load` refuse and denied world entry (availability, not privilege). Tag 4 is now

granted by any code; when collection-node-pickups wires them it must grant from server-owned
tables after a server-verified outcome and check ownership, as T523's threat note already says.
No secret, no copied AGPL code (data rows only), no new client-triggered allocation.
