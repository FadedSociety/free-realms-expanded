# T702: boombox picker fields and 42/6 binding

## Summary

The native run (`lab/autopilot/native-notes/2026-10-25.md`, 15:28Z) gave the Rainbow Randomizer
Boombox (1913) but the Stuff detail pane showed no action button and a drag from that list did not
bind it. The client has two different panes:

- The **item-bar picker** and the character window's **Consumables tab** read the
  `BaseClient.Inventory.Consumables` data source. A row is kept when the item definition's type
  (`+0x6c`) is 1, its activatable ability (`+0x8c`) is positive, its gender usage fits
  (`00bae6a0`) and `count - stored - consumed > 0` (`00c31de0`). Selecting a row sends 42/6.
- The **Stuff detail pane** is not a bar-binding path. (R) The lead's decision (below) accepts that
  its missing button is expected for a type-1, slot-0 definition.

The definitions the server already sends for all 15 catalogue boomboxes carry every field the
picker and the Consumables-tab row read: type 1, ability 257/255/... > 0, gender 0, slot 0. No
production or content change is needed; this task pins those client fields on the real 38/2
definition, pins the 42/6 bind and the T461 press through `Gameplay::handle_in_world`, and records
the corrected native check.

target (T459/T461 tests). The new tests only read server content and drive the production grant and
bind/press paths; they add no writes outside the test's own inventory clone.
