## Scope

Shard S0248 covers 43 functions from 009392c0 through 0093d740. Ghidra pseudocode, bytes, and vtable references came from the read-only native-map export. Packet catalogue names are community protocol evidence only; they do not establish original server logic.

## Client updates and input

- 009392c0 is the shared BaseClient/PlayClient slot-70 handler for BaseClientUpdatePacket. It dispatches health/mana, inventory/equipment, collections, profiles, effects, coins, action-bar, preload, and storage updates.
- 0093af90, 0093b340, 0093bba0, and 0093bcc0 process gated position/input events. Event kind 8 emits click-move; 0093bcc0 constructs Target and stores two supplied coordinates before forwarding. The click-move subtype is absent from the packet catalogue, so its wire record remains empty.
- 0093bff0 builds CommandPacketSelectPlayer (family 26, sub-opcode 19). Native Combat Controls.md connects the caller to closest interaction. Server effects remain a hypothesis.

## Social and session requests

- 0093b9b0 compares the candidate name with the current profile name; equality emits FriendYourself. Two later candidate predicates block submission. Only the first emits FriendAlreadyOnList. If both are false and the gateway is active, it builds CommandPacketAddFriendRequest (family 26, sub-opcode 14) and submits through PacketTunneledClientWorldPacket. The old draft misread the stack-cookie expression as a third compare argument and described the second predicate as a friend-list duplicate check; neither is supported by the bytes/body.
- 0093b730 constructs ReportPacketReportPlayer and conditionally serializes/sends it through PacketTunneledClientPacket when the gateway exists, then invokes PlayerReported. Lookup failure invokes PlayerNotReported. The report subtype is absent from the catalogue; endpoint behavior remains a hypothesis.
- 0093bd80 sends EncounterParticipantResumePacket through PacketTunneledClientPacket; constructor 008a3250 sets sub-opcode 122 in encounter family 41.
- 0093be30 sends the same packet with a byte at offset 0x14. Its sole caller, 00c171d0, parses Lua OnPaidRevive input and passes a boolean. Paid-revive use is therefore a client-side caller inference, not verified server behavior.
- 0093bec0 sends OneTimeSessionRequestPacket through PacketTunneledClientWorldPacket. Its caller is ClientInGamePurchaseManager. 0093bf50 logs a China SNS one-time-session request and uses the same tunnel. Ticket response behavior is not shown.
- 0093d740 accumulates timing/activity values and sends a snapshot through PacketTunneledClientPacket after 15000 ms. Metric meanings and endpoint use are unknown.

## Asset definitions and readers

- 0093c150 initializes SensoryEffectDefinitionManager<ActorModelMaterialDefinition,256> and its 256-bucket map. 0093c200 adjusts ECX by -4 and jumps to 0093c630; it has no destructor body. 0093c630 contains the scalar deleting destructor.
- 0093c210 tests the signed field at +0x3c; 0093c230 returns that field. 0093c220 returns +0x34, whose meaning remains unknown. 0093c370 RTTI-casts to ActorModelMaterialDefinition and returns +0x60. Insertion at 0093d030 shows +0x60 is the next intrusive-list link, so the refined accessor name has likely confidence.
- 0093c3a0-0093c5a0 initialize string/map entries and clean up manager-owned records. 0093c4a0 links a copied node at a bucket head selected by the low key byte and increments its count; allocation failure reaches a null dereference. 0093c670 repeatedly passes the current head to 0092ad20, which unlinks records and releases string members.
- 0093c530 inserts a name-map entry, stores its identifier, then dispatches virtual slot 5. The derived manager vtable routes that slot to 0093d0e0; it does not call a base-manager add routine. 0093d030 appends and indexes ActorModelMaterialDefinition nodes, updating both list links and the key-byte bucket.
- 0093cc80-0093d160 specialize the manager for ActorModelMaterialDefinition. 0093cee0 initializes the asset-request interface, IString, and ModelMaterialParameter list.
- 0093c790, 0093c840, and 0093ca50 are bounded readers. Native Opening Quest Journal.md cites 0093c840 as a quest-record decoder; 0093ca50 remains an unidentified record type.
