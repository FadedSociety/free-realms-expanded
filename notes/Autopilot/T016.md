# T016 - Stone Heart's Hideaway battle

## Result

Build Plan 2.7 now has a fourth playable field battle (R), built on battle
96's existing schema and route. `Stone Heart's Hideaway` is battle id 12303,
entered through the recovered Legacy entrance marker 4750. The scripted test
covers the marker screen, arena entry, all four enemy spawns, the recovered
goal, ordinary attacks, one rewarded win, result close, world return, and a
duplicate close that changes nothing.

Stone Heart's Hideaway was selected from `data/content/dungeons/` because its
record has a resolved client title and objective, resolved boss and minion
locale/model pairs, resolved local enemy definition ids, a known entrance
transform, and a named Brawler prize. Its original instance scene, phases and
complete wheel are not resolved. The playable arena therefore remains the
shared reconstructed arena 9600.

- The original instance scene is unknown; zone 9600 is a reconstructed
  fallback shared with battle 96.
- Boss abilities, health phases, invulnerability semantics, minion
  self-destruct/chaining, doves and the flower objective are not implemented.
- The level-13 requirement is displayed through difficulty 5 but is not
  enforced by the existing battle route; the test uses a level-13 Brawler.
- No original wave order, arena transforms, coin payout, members-only policy
  or daily repeat rule is recovered. The battle remains repeatable under the
  existing field-battle policy.
- Only the Brawler wheel outcome is represented. The other five job weapons,
  house/clothing/fluff prizes and native wheel presentation are unknown.
- No native client run was performed. Visual marker, arena, AI, collision and
  wheel animation remain lead/native acceptance work.
- The Rust test starts through `EncounterEngine::begin()` rather than the
  gateway's 41/108 handler. The existing 41/108 route is covered separately,
  but no packet-level regression test names battle 12303.
