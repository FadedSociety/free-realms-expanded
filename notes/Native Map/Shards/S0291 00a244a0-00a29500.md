## Structures and subsystems

This range combines generic SOE utility containers, lobby UI data sources, and encounter packet record readers/writers. Vtables identify participant hash maps and lists, team lists, and the lobby game/encounter data sources (00a24b00?00a25eb0, 00a26f30?00a27890). The lobby sources register `BaseClient.LobbyGameList` and `BaseClient.EncounterGameList` (00a27190, 00a27250); their column callbacks select or format row values for UI output (00a24a60, 00a25870, 00a25a40). The manager constructs and tears down both sources and its encounter registry (00a29370, 00a29500). Destructor 00a28360 drains the same head at +4 in its bounded and base-vtable phases; the base phase therefore sees an already-empty list.

The red-black tree helpers and pool code are generic container mechanics (00a24da0?00a25690, 00a27960?00a28280). Both keyed lookup helpers (00a24f70, 00a27b40) return an exact node or a predecessor-side candidate; the equality path follows predecessor links, so neither is a successor-based lower-bound search. The second pool's block slots advance by 0x374 bytes (00a28090), and its allocate/free virtual methods are in `SoeUtil::List<SoeUtil::HashList<EncounterParticipant,25,5>,-2>` (00a282f0, 00a28340). This ties the pool to the bounded participant-map list; the prior `EncounterDetailPool` suffix overstated its domain. Its descriptor tree operations at 00a27e80 and 00a27ee0 insert and remove block descriptors.

Counted encounter readers clear prior entries, consume a count, then append/decode teams and nested participant maps (00a25f10, 00a267e0, 00a27610, 00a24660, 00a29120). Writers separate outer team count from each team's member count: 00a27750 writes the outer team list, while 00a27340 writes one team's members and delegates each member record to shared helper 00a26bf0. That record helper is also called by matchmaking code at 00c08870, so its field semantics remain generic and unresolved. The nested detail serializers form a separate chain: 00a263d0 writes participant collections, 00a26940 writes a common detail record, 00a286f0 writes a counted detail list, and 00a28800 writes the nested payload without writing the team list; 00a28e20 writes the team list before calling it.
