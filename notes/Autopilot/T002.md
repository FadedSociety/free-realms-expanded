## Security and review decisions

- A client profile id only selects a preloaded row for that NPC; the open menu, zone, 12 m range,
  exact offered option and trainer pair must all match.
- Service rejections (out of range, unoffered option, wrong active menu) return an error; the
  gameplay refusals (already known, busy, unavailable/forged profile, unmet rank) return a chat
  line with `changed = false`. The staged clone is discarded and the save is untouched.
- The loader is bounded and rejects zero ids, unknown profiles, duplicate NPC/job pairs and
  invalid prerequisites. No new packet, dependency, network surface or persisted state was added.
