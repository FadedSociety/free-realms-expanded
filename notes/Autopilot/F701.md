## Security threat note (secure-code-guardian)

A hostile client can still only send a 26/8 request with a u64 target guid; it cannot name a node
file, tag, spawn id, type or reward, and nothing from the client reaches `node_guid` or
`GatheringNodes::load`. The new code is a `cargo test` integration test and note corrections; it
copies committed content files into `%TEMP%` dirs and deletes them. A reused guid tag can only
collide two server-authored actors, which would refuse world entry or alias visibility
(availability/identity, not privilege). No save, coin, item, reward, role, chat, session or
trade path is touched, and no secret or AGPL code is copied (the data rows remain T523's pinned
community data). The collection drops remain unread by any runtime code.
