# S0026 findings (0047ca5e..004823b9)

This range is ForgeLight-family GFC graphics/font infrastructure. It contains GFC surface allocation, clipped/scaled blitting, GDI presentation, image-codec helpers, color/math routines, FX records, cursor properties, and text/device state helpers. No target builds, sends, parses, or dispatches a network packet; there is no wire-backed original-server inference in this shard.

## Systems and connections

- 0047ca5e creates DIB-backed or allocator-backed surface storage; 0047cd36 clips and copies surface pixels across matching 1/2/3/4-byte layouts; 004814ba presents a surface to a Win32 window with GetDC/SetDIBitsToDevice.
- 0047e728 expands bit masks into planes only when header byte +3 is 1; 0047e8a4 handles marker/run expansion and 0047e9ed emits repeated-byte runs. 0047e586, 0047e6f5, 0047eb49, and 0047ec59 register BMP, PCX, PPM, and TGA codec classes. Static addresses 01768ea0, 01768eb4, and 01768ec8 resolve to factory-pointer/name records, not MSVC vtables.
- 0047ef15/0047f14e and adjacent routines convert color representations; 0047f14e computes byte-scale saturation with (diff*510 + max)/(2*max), so the result is 0..255. 0047f446 complements three channels and extracts/subtracts their minimum; byte order alone does not identify C/M/Y or RGB/BGR.
- FX class vtables directly bind slot-1 global-pointer accessors (004801e5, 00480302, 00480431, 00480536, 00480689) and slot-64 checked copy overrides (004802a3, 004803c6, 004804ef, 004805fa, 0048074d) to GDrawFx/GLineFx/GFlashFx/GFillFx/GBlitFx. The bodies show global stores and field copies; they do not prove the globals are initialized default instances.
- 00480f0b is destructor-path cleanup: it calls the two-buffer helper on object offsets +0x68 and +8, covering four counted-buffer fields. 00481081 allocates a fixed 0x38-byte block and 0048108a calls _free with a stack epilogue.
- 004823b9 reads named String and StringFormat properties into offsets +0x34 and +0x38; the property key does not establish printf semantics.

- Earlier notes/Native Map/Classes/engine.gfc.core.md wording characterized 004823b9 as printf-style. The body only reads the StringFormat property; its interpretation remains unknown.
- 0047cd36 returns 1 for the paired 0x20/0x10 flag case and for nonpositive clipped spans; this is not a general fully-clipped result.
