## Security threat note (secure-code-guardian)

- Surface: the suite is a hostile-client-shaped driver of the real server
  (SOE handshake, login, movement, chat, developer command). It sends only
  fixed synthetic values; no real names, chat logs or environment data.
- What a hostile client could send and why it is refused: a non-finite or
  over-`1_000_000` movement component is refused by the reader (session
  contained error); a parseable gross pose is refused by `movement::validate`
  and answered with the server's 38/12; a truncated 125 body is contained; a
  duplicate login or an abandoned session's relog is refused before any save
  read/write; a `Player`-role session with dev tools off cannot run
  `realm give 10` (refused, audited, no pose/save change). The ordinary flow's
  log check covers no denial, no budget refusal, no name, ticket or peer
  address; the role test expects exactly its one `dev_command_denial` row.
- No parser, save, coin, item, reward, role, chat, session or gateway code is
  changed; no secret or real name is added.
