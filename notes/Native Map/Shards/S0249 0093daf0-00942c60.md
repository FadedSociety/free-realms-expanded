## Byte-level correction pass

Raw x86 shows the actual receivers: `0093faf0` passes `this+0x2c` to `0093f810`; `0093fdb0` constructs its IString at `this+4`; `0093ff40` destroys the name map at `this+0x440`; `00940c60` and `00940e60` construct records in stack-local buffers; `009413e0` calls `0093ff40` with `this`; and `009417c0` calls `0089b800` with `this+8`. Direct cookie expressions at `0093fe40`, `00940800`, and `00941310` are no-argument calls through the map/allocator receiver. `009419d0` calls the zero-argument singleton getter `00fbe740`.

The independent review also exposed and these records correct: `0093f630` uses a direct helper for the mask-8 pair update; `0093fed0` copies the input string into the inserted entry and does not pass its constructed map key to the manager virtual call; `00940980` tracks remaining free nodes, not live nodes; `00941750` clears only element 0, not elements 0 and 1; `009413c0` is `ActorCompositeEffectDefinitionManager::InsertDefinition`; and `0093fd10` is a manager virtual, not a definition method.
