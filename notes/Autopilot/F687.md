## Review finding 2 -> change

The review named three claims in the T514 final report as inaccurate. The fix:

1. **Missing full-field frame check in the gateway test.** `final.md` item 10 said the gateway
   test "decodes the real frame and checks every field", but
   `tests/fishing_scene.rs`, test
   `the_gateway_zones_into_the_hole_saves_the_world_pose_and_brings_the_player_back`, only
   asserted the scene name and id of the hole frame (plus the return id and position), so a
   wrong `type_id`, `sky`, `tutorial`, `unknown`, `update_radius`, `geometry_id` or boolean could
   pass the only gateway-level test. The test now asserts the **whole decoded `ZoneTransition`**
   from the opcode-31 bytes the gateway actually sends, all 13 fields, with the expected values
   written out and the client-reader field order named in the comment. The Gameplay test keeps its
   own copy of the same expected values (checked before encoding).
2. **"No hand-written check" (item 4) was false.** `src/gameplay/housing.rs` added the inline
   127/19 start-gate condition `activity_busy() && !is_occupied(Housing)`. Corrected in
   `notes/Autopilot/T514.md`; the code is unchanged (review finding 4, a MINOR the lead scoped
   out).
3. **"Hands off session plumbing" (item 16) was false.** `src/gateway.rs` `snapshot` and
   `reset_session` call the house-or-hole hooks. The lead signed those two hunks off (finding 1,
   `lead-signoffs.md` 2026-10-25 T514); the note now says so. The code is unchanged.

The original report (`final.md`) lives under `lab/autopilot/runs/...`, outside this worktree and
left in place per the cleanup rule. `notes/Autopilot/T514.md` is the tracked record and now
carries the corrected items 4 and 16, the strengthened item 10, and a short "F687 corrections"
section.

**No production code changed.** The frame is produced by `FishingService::Scene::zoning` ->
`Gameplay::start_fishing_trip` -> `Gateway::handle_at` -> `zone_transition::encode`, and the test
decodes the bytes with `zone_transition::decode`; the change pins all field values on the wire.
