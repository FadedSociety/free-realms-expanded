## Threat note

Only Admin reaches `realm coin` (existing role gate). The real boundary is server-owned file
access: nobody but the server process and the operator writes `collection_coin_edits.json`. A
semantically valid hand-edited row does reach every client; a malformed or hostile one does not,
because `read_overlay` caps the read at 1 MiB, checks the schema and the `next_guid` band, and
`merge` validates every row (band, entry, tier, model, finite position, 512 rows). A command given a
bad file refuses and leaves it byte for byte.
