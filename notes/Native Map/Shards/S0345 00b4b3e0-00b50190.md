# S0345 — ScreenshotManager: capture store, capture pipeline, portrait upload (00b4b3e0..00b50190)

Mapped by a Claude Haiku worker (41 functions; validator `valid_records=41 errors=0`; confirmed 26, likely 7, speculative 8). Replaces earlier carried labels in this range.

- **Capture store.** `ScreenshotManager` holds `SoeUtil::HashListMap<int,ScreenshotManager::StorageNode,100,-1>` at +0x80 (manager ctor `00b4e810`, map ctor `00b4e730`, buckets +0x94). Kind keys (string hash `00705bc0`, reproduced in `scratch/hash_check.py`): PORTRAIT `0xd7a6acc7` (`00b4bd40`, `00b4fd60`), HEADSHOT `0x2095e230` (`00b4bb50`), PHOTO `0xd599dc1d` (`00b4d2e0`). Lookup `00b4b840`; get-or-create `00b4e650` returns the node in EAX.
- **Capture pipeline.** SetupCapture overload `00b4b520` (own log strings; the other overload is `00b4afa0` in S0344) gates PHOTO `00b4e970` (via `00b4c850`), TCG `00b4e9f0` (0x33c×0x3ba), portrait `00b4eba0` (330×180, ids 4/9), headshot `00b4ed20` / `00b4f190` (70×70); all end in DoCapture `00b4d540` (tiled render → PNG, `playerGuid` logs).
- **Portrait upload.** `00b4fd60` builds a multipart body using the `UploadUrl` setting; HTTP completion `00b4cf00` = ScreenshotManager vtable slot 3. Only `00b4fc30` has a catalogue packet (PacketTunneledClientWorldPacket, sent via `00926360`). Portrait CRC packet (`00b4a9c0`, opcode 0x73) is not in `packets.tsv`. Gate flag at engine+0x280 (not the manager's).
- **Earlier-pass errors corrected here.** `00b4f7d0` reads source+4/+8 (not +0x10/+0x14); `00b4faa0` does stored lookup → file read (`00b4f5a0`) → default (`00b4b240`); CreatePhoto `00b4e970` always returns false as written (`00b4c850` clears AL on every exit); `00b4e650` is not void.
- **Lead check.** S0344's `00b4afa0` SetupCapture keeps its name but was downgraded to likely for wrong details (vcall +0xe8, receiver of `00cc5a30`).
- **Open.** DoCapture `00b4d540` is void in Ghidra but callers test it as a bool; `00b4c850` is `ret 0x28` vs CreatePhoto `ret 0x24`; `00ad3190` / `00ad31f0` / `00ad61f0`; success-path store in `00b4f5a0`.
