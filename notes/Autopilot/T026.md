# T026 Freeze activity content into the playtest bundle

## Port of T026-a1 (why attempt 1 did not apply)

`T026-a1.patch` was cut before T018 landed. T018 added `crafting_stations.json`
to `OPTIONAL_REPOSITORY_CONTENT`, so the old hunk context no longer matched.
`git apply --reject` applied every other file and rejected only that hunk in
`scripts/bundle/bundle_common.py`. The hunk was ported by hand: the activity
files left `PRIVATE_CONTENT_FILES`, `fishing_spots.json` and `mining_nodes.json`
left the optional list, `ACTIVITY_CONTENT`/`ACTIVITY_MAX_BYTES` were added, and
T018's `crafting_stations.json` entry was kept. The `.rej` file was deleted; the
tree has no `.rej` or `.orig` files.

## What changed

- `prototype/osfr-tools/data/content/` now carries the exact round70 bytes for
  `encounters.json`, `encounter-template.bin`, `kart_entry.json`,
  `kart_lobby.json`, `mining.json` and `harvesting.json`. `kart_gates.json` is
  committed as reconstructed (R) policy; the builder's generated copy is only a
  fallback for old trees. `fishing_spots.json`, `mining_nodes.json` and
  `harvest_nodes.json` were already tracked and are now required activity content.
- `scripts/bundle/bundle_common.py`: new `ACTIVITY_CONTENT`, `ACTIVITY_MAX_BYTES`
  and `check_activity_content()` validate the frozen kart, fishing, mining,
  harvesting and encounter set against bounds that mirror the Rust loaders. The
  check includes the T028 loader gate: a `kart_entry.json` race schedule must
  reach `countdown: 0`, or the server refuses to start. The optional list keeps
  T018's `crafting_stations.json` and W176's `job_trainers.json`.
- `scripts/bundle/make_bundle.py` runs the activity gate before writing the
  manifest. `--content-source DIR` is a verification-only override that copies a
  plain directory instead of `git archive HEAD`; the default remains committed
  HEAD. `scripts/bundle/check_bundle.py` prints and validates the same gate.
- `scripts/content_check.py` no longer applies its unique-`key` rule to
  `kart_lobby.json`: that file is the five-table 102/2 wire body, where `key`
  groups ordered rows and repeats by design. The file's CRLF endings are unchanged.
- `prototype/osfr-tools/src/kart_gateway.rs`: module doc comment only (the binding
  is no longer a private lab template).
- `prototype/osfr-tools/tests/bundle_activity_content.rs`: proof that the frozen
  files load from a temp directory holding only `data/content` files, exact hash
  pins, and refusals that leave the directory unchanged.
- `notes/Design/Playtest Bundle.md` records the required/optional lists, the T028
  schedule gate and `crafting_stations.json`.

## Open gaps

- Only activity content is frozen here. The bundle still overlays the private
  `opening.json`, `profiles.json`, `inventory.json`, `item-catalogue.json`,
  `journal-text.json`, `quests.json`, combat templates and crafting files from
  the round70 package. A server start from `data/content` alone is therefore
  blocked: `Gameplay::load` requires `opening.json` before it loads mining,
  harvesting or kart content. The bundle smoke covers the real start because
  those files ship in the bundle; freezing them is a separate decision.
- No native-client run was performed. The bundle checker proves login, gateway
  startup and a bot walk from bundle content, not visible minigame play.
- `kart_gameplay`, `kart_lobby_gameplay` and several encounter/fishing private
  gates remain ignored without their private fixtures.
- The Python activity check mirrors the Rust loaders; a future loader change must
  update both (T028 needed exactly this). The hash-pinned Rust test exercises the
  real loaders.
- `--content-source` exists only for pre-commit verification; integrated bundles
  use committed HEAD.

## Security-relevant decisions

No launcher, login/session, account, transport, trade or other lead-only module
was changed. The verification content source is a regular directory only
(symlinks and non-files are refused), and the activity gate fails closed on
missing, oversized or mismatched content. Saved-state compatibility is preserved
by the exact round70 bytes, including the kart entry and encounter hashes.
