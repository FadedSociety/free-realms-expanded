## Security threat note

The added view path accepts no client instance id, target, or packet fields.
The instance is read from server membership, and removal occurs only for the
same authenticated session after server-observed readiness/world-load loss.
A hostile client can trigger repeated load/readiness transitions at most,
causing bounded 35/3 messages for actors it already knows and a self-only view
refresh. It cannot remove another session's actors, grant rewards, alter coins
or inventory, consume menus, or advance attempts. The new readiness helper is
`#[cfg(test)]` and uses the existing reset/membership APIs; it is absent from
the shipped binary.
