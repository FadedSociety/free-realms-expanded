# T454 - Pet catalogue from client data: every pet model, pet item and trick (lead build, 2026-10-26)

Built by the lead (the owner, 2026-10-26: "you could finish up the pet stuff ... build it out and then send it for
testing"). Base: verified tip f4362c1d.

## What changed

- `scripts/pets_import.py` (new): reads Pets.json (Sanctuary-main 10f129e, data facts only), the Legacy
  ClientItemDefinitions.json (9e08202), client Models.txt and the client locale, and writes `pets.json`'s new
  `imports`, `models` and `items` tables plus the trick display fields. It only reads its inputs and writes
  `pets.json` deterministically: two runs give sha256 `4144747adbee2d6044b91a60413b1ef669fcd9eee3b05b52c492f1df1015924b`
  both times. Everything else in `pets.json` is byte-for-byte unchanged (the file round-trips through
  `json.dumps(indent=2, ensure_ascii=False)`); the diff is additions (a histogram diff shows 13,959 added, 7 removed lines: the
  trick list grows in the middle).
- `src/pets.rs`: `PetContent` gains `imports`, `models` (`PetModel`), `items` (`PetItem`); `PetTrickDefinition`
  gains optional display fields and an optional `waypoint_count` (absent = no gesture record). `MODEL_IDS` is gone:
  `PetContent::model_id(adr)` reads the models table (lowest id per ADR, (R)), and all 26 previously bound ADRs map to
  the same ids. `definition_for_item` looks in the items table first (species: the wiki species that lists the item,
  else the item id (R)); `definition` takes its initial tricks from the model. New accessors `model`, `item`,
  `is_vanity`. `validate` rejects duplicate model or item ids, an item whose model is not in `models`, a model trick
  not in `tricks`, more than 16 tricks or item classes on a model, and an item id equal to a wiki species id.
- `tests/support/pet_inventory.rs` (new, moved from `tests/pets.rs`): the shared inventory fixture, now
  `InventoryFixture::with_items(&[(instance, definition, count)])`; `new()` keeps the four items `tests/pets.rs` used.
- `tests/pet_catalogue.rs` (new): the brief's gates.
