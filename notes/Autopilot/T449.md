### Threat note

The file is server content; no client packet reaches the loader. A bad or hostile file is still refused whole:
- the read is bounded (`take(1 MiB + 1)`);
- unknown fields are refused, and only schema 1 loads;
- `pickup_range` must lie in 1..=50, which excludes 0, NaN and infinity. JSON NaN fails to parse, and 1e39 becomes
  f32 infinity and is refused;
- a duplicate guid, a duplicate entry, an entry the catalogue lacks, a wrong owner collection and a tier/collection
  mismatch are each refused. A coin can therefore never tick a non-exploration collection.

When T450 wires the pickup, it must still check range and visibility server-side. The map only says which entry a
known guid ticks.
