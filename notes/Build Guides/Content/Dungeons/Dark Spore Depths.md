## Conflicts

1. **Set-name spelling.** Every wiki wheel item matches the client spelling. The one difference is the wiki bonus-set name "Enery Transfer", which the client spells "Energy Transfer" (`loc 176942616`). Client used.
2. **Coin figures hidden in the wiki text.** The wheel and members coin numbers are blank in the page text and recovered from template fields. The wiki's own text therefore does not state them.
3. **Achievement spelling.** The client achievement strings use "Dark spore Depths" (lower-case s) while the name string uses "Dark Spore Depths". Name spelling used.
4. **Dev tags.** Two client strings label the dungeon "NOT LIVE". Wiki and video show it as a live Atlas dungeon. The wiki page is dated 2025, so it is treated as live.
