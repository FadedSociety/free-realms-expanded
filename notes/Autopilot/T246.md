## Security threat note (secure-code-guardian)

- Hostile client input on this path remains the existing 26/8 target GUID and
  the 26/10 NPC GUID/option pair. The router resolves the target through
  `content_npc_key`, requires an open menu for that exact NPC, and rejects an
  unknown or out-of-list choice with `InvalidOption`; the new tests assert the
  refused choice leaves the menu usable. No greeting id comes from client
  bytes: it is a `u32` read from server content, so a client cannot inject
  text, choose a locale id, or trigger an allocation from attacker-controlled
  size.
- No save, coins, items, rewards, roles, chat or trade state is touched. The
  change only adds static content rows read by every session; no per-player
  state and no new entry path. Loader bounds (8 MiB/file, 32 MiB total,
  20,000 rows) are unchanged and asserted by the bounded-content test. The
  locale id resolves in the stock client file, so no overlay/fallback path is
  introduced.
