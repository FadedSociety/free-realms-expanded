## Scope and classes

This shard is primarily UI data-source code plus generic containers. `BaseInventoryDataSource` and derived equipment/vehicle/rental/pet/fishing/broker views share cell and rebuild methods at `00cb0c60`, `00cb1160`, `00cb1340`, and `00cb1500`. `BaseClient.Inventory` is bound in the base constructor at `00cb1bb0`. The 18-item inline `ItemGuid` array used by that source has its constructor, allocator, destructor, and clear path at `00cb0d70`–`00cb1250`.

`ProxiedCharactersDataSource` owns a 0x38-stride row array. Its constructor/destructor and update/get-cell paths are `00cb2920`, `00cb2810`, `00cb28c0`, and `00cb29e0`; `00cb1ce0` supplies common NPC/target/proxied-character column names. Generic list/array utilities in the shard include callback-driven list reordering (`00cb0bf0`, `00cb0ea0`), pointer-array operations (`00cb3070`–`00cb3410`), linked-list operations (`00cb5670`, `00cb59f0`), and pair-array search/removal (`00cb57c0`, `00cb5810`). Add/remove handlers at `00cb4da0` and `00cb4ee0` update the cache and emit the `FriendAdded` / `FriendRemoved` UI keys. Their snapshot and hash-list helpers are mechanically mapped; feature attribution for helpers without their own friend string or RTTI anchor remains contextual.

Guild UI sources bind `BaseClient.Guilds` at `00cb6120` and `BaseClient.GuildMembers` at `00cb6260`. The 15 guild-member columns match the recovered schema in [[Research/Pieces/090 Guild lifecycle]]. That note independently records original packet ids and payload limits alongside community-only server rules; this shard does not revise those protocol findings.
