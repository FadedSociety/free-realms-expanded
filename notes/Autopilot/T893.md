## Learn handler is keyed by (NPC, profile), not by NPC

`NpcInteraction::select` finds the row by `job_trainers[npc]` and `profile` (`src/npc_interaction.rs`, `NpcAction::Learn
{ profile }`), and `Profiles::learn` only reads the row's profile and prerequisite. Several NPCs per job, and several
jobs per NPC (Silverray, Doctor Gordon, Derp Axemaker, Mayor Crystalline, Smitty, Mili Ironcall), work with
no code change. Client facts: menu labels are locale ids ("Become a ..." 412437 and so on, 2014 en_US locale).
