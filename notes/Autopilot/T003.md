## Reconstructed rules (R)

- A 45/7 claim advances only a content-marked `ClientReported` goal open on the
  character's own active quest; it never awards or bypasses NPC turn-in.
- Client ids are unique catalogue-wide and positive. Look range/angle, event name
  bytes, offset and the wire length are bounded; malformed claims are rejected
  before any state change.
- Registration is once per id per session. A goal reopened after abandon is
  re-armed with 45/9, never registered twice.
- A 49/15 start must name a listed original id. Unlisted or forged ids change
  nothing and receive one fixed system refusal line. Listed ids still pass the
  normal offer checks, so hollow or disabled targets remain refused.
- Four crosswalk mappings are defensible from title/activity evidence:
  1805 -> 3050009, 1808 -> 3050013, 1811 -> 3050004, 1881 -> 3140001. All four
  targets are hollow and disabled in the current catalogue.
