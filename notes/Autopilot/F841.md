## Threat note (secure-code-guardian)

A hostile client can send 53/16 fit requests with any utility slot and instance id. The fit path is
unchanged: the slot must be 1..=7 (out of range echoes nothing, F778), the instance must be owned, the
definition must be type 4, its client Slot must equal index + 199, and its class must be on the pet
model. The change only moves the server's own slot arithmetic into `KitRole`; it cannot accept a new
slot. 53/19 (feed) still carries only the pet id: the server picks the fitted bowl/food, requires both
to be recorded kit rows in their role, and spends exactly one owned unit through `Inventory`'s staged
transaction; a stale non-kit item is refused and changes nothing. The price change is server content
(15 coins from the client definition), not a client word; the buy path still checks the vendor stock and
the player's coins. No new network surface, no path/id from a packet reaches the file system, no new
persisted state. Test-only lab reads are gated and never run in production.
