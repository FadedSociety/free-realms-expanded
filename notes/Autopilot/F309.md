## (R) rules

- Per-character relay budget: 10 relays/second, burst 4 (lead-accepted,
  `lead-signoffs.md:31`). The key is forgotten by `end_session`; a reconnect
  starts with a full burst. Over budget only the 164 drops; the validated pose
  still fans out through 125.
- The relay clock is the dispatch time (`now_ms`, server uptime) anchored at
  the session start. It is monotonic, server-owned, and independent of the wall
  clock, so a slow commit cannot refill the window mid-flood.
- Vertical velocity: finite values are clamped to +/-100.0 (10x the 10 u/s 125
  base); non-finite values and invalid poses are refused. The 100.0 bound is a
  compiled (R) value and remains an open lead decision (finding 4).
- Wire layout is unchanged: `u16 164, u64 guid, 3 x f32 position,
  3 x f32 direction, u8 state, u8 unknown, f32 vertical_velocity`; `state` is
  relayed opaquely with the 164's impulse.

## Security threat note (secure-code-guardian)

A hostile client can send a 164 for another character GUID (refused: only the
session character is accepted), a short/trailing/wrong-opcode body (refused
before staging), NaN/Inf/out-of-range position or direction (refused by
`jump_relay::decode` + `movement::validate`), a huge finite velocity (clamped,
never a disconnect), a state byte without bit 2 (relayed opaque; the sender
only loses its own animation) or a 164 flood. The flood is capped per character
at 10/s burst 4; over budget only the extra 164 drops while the accepted poses
still fan out through 125 (the same directed set). The limiter key set is
bounded by `MAX_SESSIONS`, and `end_session` removes the character's key, so a
reconnect starts fresh (now tested end to end). The limiter is charged only
after a successful commit, so a refused or failed transaction neither spends
nor refunds a relay. The clock is server-derived `now_ms` from the tick, never
client input; an unreachable `Instant` overflow is theoretically possible only
after hundreds of millions of years of uptime. No items, coins, rewards, roles
or other player-triggerable economy state are involved; no secrets or names are
logged.
