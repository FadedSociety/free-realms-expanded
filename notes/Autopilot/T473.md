## (R) choices
- Ids: buff ids 1_000_000_000.., world tags 1_500_000_000.. (500M range each), skip live ids, wrap at top.
- Bounds: duration 1..=86_400_000 ms, delay <= 10_000 ms, scale 0.25..=5.0 (finite), model id and aura
  composite id must be positive. Constants with comments, not tuning values.
- One slot per kind (3 slots), so the brief's "at most 16 live effects" can never be reached: the cap
  and its 17th-effect refusal do not exist (the slot array is the cap). Reported to the lead.
- `ends_at = now + duration_ms`; an aura's `delay_ms` delays only the 35/41, not the row or expiry. An
  aura that expires before it starts sends only 38/17.
- `resend_to_self(guid, now_ms)`: takes the clock (remaining time needs it) and sends 35/14 and 35/13
  only when a transform or scale is live, plus a 35/41 per started aura and a 38/16 per effect.
- Transform with `poof_effect_id` 0 plays no poof. Replacing a transform sends the old 38/17 first.
- Expiry order is the brief's: 35/15, 38/17, then the aura resync (not Sanctuary's resync-before-38/17).
- Mounted players get 35/14 anyway (client defers it, `0096bd90`), (R) until the native check.
