## Security note (secure-code-guardian)

Threat: a hostile client can click any of the four drivers (26/8) and forge any 26/10 option id,
including a derby choice, when no package exists. The dormant path refuses because
`DerbyGateway::load` returns `None`, so `set_derby_gates` is never called and no derby option exists
for `NpcInteraction::select` to accept; an unlisted id is rejected before any staged transaction. The
test proves byte-identical saves and no 39/x reply at all four gates, so the forged path cannot start
a match, switch jobs or move coins. No new trust boundary, parsing, persistence or economy code was
added.
