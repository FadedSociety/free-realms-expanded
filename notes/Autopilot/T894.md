## Guards extended (not weakened)

Five older suites pin "no other row in this region gained a greeting". Each failed on exactly the
row(s) this task binds, so each got the new binding added to its own list of later bindings; no
assertion was loosened and no test was removed or renamed:
`npc_greetings_highroad_farnum.rs` (new `LATER_GREETINGS`, Sammy), `npc_greetings_job_hubs.rs`
(`EXISTING_GREETINGS` 23 to 25: Bruce, Roland Sporeling), `npc_greetings_lakeshore_wilds.rs`
(`LATER_GREETINGS` 3 to 4: Tooga), `npc_greetings_sanctuary.rs` (`LATER_GREETINGS` 3 to 4: Abacus),
`npc_greetings_merry_vale_stillwater_remaining.rs` (new `LATER_BOUND`, Rylan).

A sixth suite, `npc_greetings_merry_vale_stillwater.rs`, failed only on the committed tree: its change
guard `the_existing_greetings_and_other_regions_are_unchanged` allowed a foreign greeting-only edit just
in the working-tree base, so after the commit it rejected the five other regions' greeting edits.
The guard now allows `is_greeting_only_change_between` in the Commit base too (the combined
quest-binding-and-greeting clause stays working-tree only); each foreign region's own suite pins its bindings.
