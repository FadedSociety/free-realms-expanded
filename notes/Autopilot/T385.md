## Security threat note (secure-code-guardian)

Content and tests only; no parser, reward or save path changed. A hostile client can
target any GUID with 26/8/26/10. The four new GUIDs are ordinary content keys, and every
refusal path already in place still applies:
- `content_npc_key` refuses an unknown actor.
- `check_range` refuses a far click.
- The shared busy table (`Occupation::Fishing`) refuses a menu or a second trip while a
  trip is open.
- `select` requires the exact offered option for the open NPC.
- `FishingService::enter` refuses a non-guide.

The suite asserts the serialized save is byte-equal after each of these: far click, far
choice, a choice naming another guide, an unknown actor, a malformed 26/8, an unoffered
choice, and a busy menu or choice. Payout is unchanged and server-owned. A dropped cast
pays nothing after reconnect.
