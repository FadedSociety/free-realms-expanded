- `client`: `Global.Text.<id> = <text> (lab/reports/locale-id-to-text.json); Models.txt

## Client evidence

`python -I lab/autopilot/ida_query.py decompile 0x00921a10` (35/2 AddNpc body reader,
`sub_921A10`): actor GUID as two dwords at +0x10/+0x14, name id i32 at +0x18, model id i32 at
+0x1c, then the one-byte flag and the transform. This matches
`startup_world::write_npc_body` field for field; the new rows add no wire field and reuse the
existing typed writer. Name id is the field the client nameplate resolves (`Global.Text.%d`,
`0x01804c14`; T252 notes).

Draw path: `NpcVisibility::load` -> `shared_view` (`world.rs:277`), called by
`Gameplay::shared_npc_view` -> `Server::sync_field_views`. Nearest-64 cap at `world.rs:22`,
radius 100 m, sorted by distance then actor id.

Known gap: `Npcs.json` marks every imported row `HideNamePlate: true`, but `ExtraNpc` has no
`hide_nameplate` field and `content_spawn_template()` sends 0 (`startup_world.rs:624,818`).
The client may therefore draw the locale names ("Rabbit", "Customer") that the original hides.
Fixing it needs a production schema field, which this brief forbids; recorded as a follow-up.

## Security threat note (secure-code-guardian)

The rows are server-authored content; a hostile client cannot inject or edit them. The only
client-triggerable surface is the 26/8 NPC click and the visibility fan-out:

- A click on any new guid resolves through `Gameplay::content_npc_key`; none of the 141 rows
  carries a `content_key` (the schema has no such field on them), so the request is the
  existing `unknown_runtime_guid` no-reply refusal and changes no menu, offer, item, coin or
  cooldown. A forged click cannot reach a vendor/quest binding through these guids.
- Every guid is `100000000000 + Npcs.json Id`, unique among extras and disjoint from regional
  actor ids (`tests/world_population.rs` asserts both), so no row aliases an interactive actor
  or the public-world instance.
- The rows are drawn through the existing read-only nearest-64 fan-out; they add no packet
  field and no client-controlled value. The cap remains deterministic (distance, then guid),
  proven by the two-viewer square test.
- Values are bounded by the existing loaders (`ExtraNpc::display_error`, finite positions,
  scale 0.1..=10); the imported scales are 0.75, 1.0 and 1.25.
