## Security threat note (secure-code-guardian)

Attack surface: family-40 invite and response packets from any authenticated
hostile client.

- **Forged/replayed generation:** a client can send any dword in the 40/4 slot.
  The server looks up the single pending invitation for the session-bound target
  and compares its generation; a mismatch returns 40/5 code 3 and mutates
  nothing (no row removal, no roster change, no broadcast).
- **Same-group replacement:** the case the old guard missed. The leader re-invites
  the same target into the same live group after expiry; the group id is
  unchanged but the generation is fresh. A response to the old pop-up is
  refused; a response to the new one succeeds. Both are tested.
- **Repeated response:** the first accepted/declined response removes the row;
  a repeat finds no row and returns 40/5 code 3, as before.
- **Target/actor identity:** the target guid is the session's character guid,
  never the packet's sender guid; names in the other family-40 packets stay
  bounded by the existing parser. No new length or index is client-controlled.
- **Economy/capacity:** group invites grant no coins, items or XP; the
  reservation-capacity check is unchanged. Refusals do not free or reserve a
  slot differently than before.
- **Overflow:** the generation increments with `wrapping_add(1).max(1)`; the
  comparison still works after a wrap, and a zero generation is never emitted.
  No arithmetic on client data.
