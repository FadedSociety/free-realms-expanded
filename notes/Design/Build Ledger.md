The previous version was refreshed on 2026-10-17 and called pets, housing, soccer, chess, derby, guilds and matchmaking "not routed"; all of them are routed now (they appear below with their evidence).

**Status words** (use exactly these):

- **Not routed:** notes, research or code that the live gateway never reaches.
- **Tests only:** routed in the live gateway and exercised by automated tests or the scripted bot, but never watched working in the real client. A row whose only real-client run failed also says so.
- **Seen in the real client:** someone ran the original Windows client against our server and watched it work. The row gives the run date and start time in UTC, for example "2026-10-21 03:33Z". Runs since 2026-10-20 are logged in the maintainers' private run notes (`lab/autopilot/native-notes/`, run folders `lab/runs/client-baseline-<date>T<time>Z`) and are not yet in `notes/Reviews/`. A row says which part was seen.
- **Playable:** a normal player can reach it and finish it without developer commands. Used only where a full loop was watched.

Dates on "Tests only" rows are the commit dates of the task that routed the system (a task id is in the commit subject `Autopilot <id>:`; most also have a report `notes/Autopilot/<id>.md`, a few lead patches do not). A rule marked **(R)** is a reconstruction.
