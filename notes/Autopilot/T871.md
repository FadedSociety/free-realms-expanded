# T871: the Station Cash Marketplace Housing category lists the original housing fixtures

## Summary

## The id key proof (lead's 2026-10-28 16:35Z note)

## Price rule

The shop has no item-data-derived Station Cash rule, so the fallback is the item's Legacy
`ClientItemDefinitions.Cost`: `sc_price = Cost`, and the existing content value
`station_cash.sc_price_scale` (0.25) turns it into `round(sc_price * 0.25)` SC at the client. The
16 wiki-priced fixtures keep their existing wiki price (basis W) because "the price our shop
already derives" exists for them. T871 rows carry `sc_basis: "C"`, `legacy_coin_price` and the
community-table citation; the `T871` tag legend explains the rule.

The 48 no-Cost rows stay exactly as they were (many already had no price); no row was given a
fabricated price. No coin vendor stocks any fixture (checked against `vendors.json`), so clearing
their coin prices loses no coin sale and opens no coin arbitrage.

## Security note (secure-code-guardian)

What a hostile client can send: a 66/1 or 66/3 order with any bundle id, store id, quantity, tint,
gift recipient or coupon, and 165/4 coin buys for any item id. Nothing new parses those packets.
The listing comes only from server content: an item enters the 66/5 catalogue only if its
`stores.json` row has an `sc_price`; the price is the content's scaled `sc_price`; the Housing group
comes from the content shelf, never from the request. The moved rows have no coin purchase price
and `no_sale`, so the coin path answers `RESULT_SERVICE_UNAVAILABLE` and a vendor cannot buy them
back; the unpriced 48 stay unlisted and an order for one is a refusal that changes nothing
(asserted with an inventory + wallet snapshot). The 48/7 exclusions are content facts, not client
input. The generator is offline, reads pinned lab copies and repo content, writes only
`stores.json`, and asserts the item model, category, tint, vendor-stock and price invariants; no
client-controlled value reaches a price, id or category. No secrets, personal data or absolute
paths were added.
