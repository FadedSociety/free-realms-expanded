preserves it. The three queries below were re-run against the current database.

- `decompile 0x008e5dd0` (35/8 reader): calls the header reader `sub_8D6830`,

- `decompile 0x008d6830` (header reader): two `__int16` reads (family, subtype),
  four bytes; matches `u16 35, u16 8`.
- `disasm 0x009315c7` (case 8 of the opcode-35 jumptable `0x0092F540`):
  `sub_8B3EE0` builds the subtype, `sub_908A50` validates, `sub_984960` resolves
  the actor; at `0x0093163d` `test dl, 1` with the flags byte: bit 0 set writes
  the id to `[actor+0x51C]` and destroys the packet, clear shifts to bit 1 and
  calls the play-or-queue routine. Ambient sends flags 0 = play now.

The 21-byte test in `src/npc_ambient.rs` and the queued-body assertion in the
gateway test both build those reader-derived bytes.

## Threat note (secure-code-guardian)

- Attack surface is unchanged: ambient is server-to-client only. No client
  packet creates, targets or chooses an animation. The only client-influenced
  input is its validated position (opcode 125 through `movement::validate`),
  which decides which passive actors it sees; `session.known_npcs` is capped at
  64 and the animation table is server content.
- A hostile or slow client can fill its own reliable queue. The existing
  `field_delivery_refused` path logs and drops that session's ambient packet;
  the field and every other viewer keep ticking. The new test asserts the
  refusal attempted the packet once, accepted nothing, changed no saved state
  and left no fault. No cross-player or shared-tick error path is added.
- Content is operator data, not client input, and stays bounded/fail-closed
  (1 MiB, 512 rows, 1..=16 ids, positive distinct ids, 500..=600000 ms,
  cap 1..=16, one row per model id, unknown JSON fields refused).
- The only client-resource reading is in tests (`tests/support/xml.rs`,
  `tests/support/models.rs`); production never links it. The runtime cannot
  reject an unknown client slot without embedding the client table, so that
  check stays in the content gate (finding 5, documented deviation).
- No secrets, saves, coins, items, rewards, roles, chat or player names are
  touched by this diff.
