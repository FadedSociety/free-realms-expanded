# T508: texture alias, tint, subtitle and scale on extra spawns

`ExtraNpc` (`src/world.rs`) now reads `texture_alias`, `tint_alias`, `sub_text_name_string_id` and `scale`
and copies them into the `NpcSpawn` it sends. They were already wire fields: `build_add_npc` writes them
for client reader `0x00921a10` (pinned by `tests/startup_world.rs`), so the wire format is unchanged.
Absent fields keep `content_spawn_template()` (aliases empty, sub text -1, scale 1.0).

## Data (`npc_spawns_extra.json`, CRLF kept, re-serialised byte-identically apart from the edits)

- 295 surviving Legacy rows gained `texture_alias` from FreeRealms-Legacy@9e08202 `Npcs.json` (matched by
  `legacy_npc_id`; the brief's 322 shrank when T468 retired 632 rows). Each row's `source` gained a
  `legacy-data` entry `FreeRealms-Legacy@9e08202 src/Resources/Npcs.json Id=<id> TextureAlias=<v>`. 294 of
  the 295 agree with Sanctuary-main@10f129e; Id 2402 (`tshirt`) is Legacy-only. The 58 skullz thugs carry
  `skullz_mohawkthug`.
- 44 of the 90 T470 Sanctuary rows gained SubTextNameId (1114, the blank string, skipped), TextureAlias,
  TintAlias and Scale (only when not 1: 1.5, 0.8, 3, 0.8, 1.5), with a `reference` source entry
  `Sanctuary-main-20261019@10f129e Npcs.json Id=<id> <fields>`. Locale check: 38093 'Card Duelist Trainer',
  24621 'Postman Trainer', 441416 'Banker' (`lab/reports/locale-id-to-text.json`).

## Brief premise that was wrong (reported)

Sam Potts, Poe Tatters, Bry and Garrison Gold are `legacy_data` regional rows (T467), not extras rows, so
`ExtraNpc` cannot give Sam Potts his 38093 subtitle. The regional loop reads no display fields and the
regional schema is a ContentDb type, so extending it is a separate task. The shipped-content gate uses
Bezzle (441416, alias `Banker`), Felipe (24621) and a skullz thug instead.

## Structure

- Graph/search: `rg ExtraNpc|content_spawn_template|build_add_npc` over `src` and `tests`; the extras loop is
  the only reader of `npc_spawns_extra.json` besides `content_check.py`. The code-graph server was not used
  (search was sufficient for one struct and one loop).
- Modules touched: `src/world.rs` (+44 lines: four fields, `ExtraNpc::display_error`, the loop copies),
  `tests/world.rs`, `tests/content_npc_spawns.rs`, the data file. No hub file changed; nothing deleted.
- Rules live on the type: `ExtraNpc::display_error` is the one place that decides which values refuse a load.
  Aliases: at most 120 bytes, no control chars (the `combat.rs` rule); scale 0.1..=10.0 (R); sub text > 0.
  An invalid row (even one the loop would skip) refuses the whole load with `InvalidData` naming its guid.
- Cost: load time only; per tick nothing changes.
