## Security threat note (secure-code-guardian)

- A hostile client can send 26/8, 26/10, 26/6, 49/2 and 49/14 at any time.
  These are the existing parsers; no new parser, selector or field was added.
- Forged 49/2 accepts for the exam, House Call and Take Your Vitamins while no
  offer is pending are rejected (`QuestDenial::Unavailable`, no 49/3) and leave
  the save byte-identical (`refusals_and_replay_change_nothing`,
  `naia_offers_the_medic_exam_only_to_medics`).
- A non-Medic cannot obtain the exam or the chapter: the offer gate is the
  server-side active-job level map (`job: 11`), the client never supplies it,
  and the job-gate canary proves the test.
- Missing prerequisites cannot be jumped (talk to Gordon before House Call:
  no 49/1, save unchanged), the wrong giver (Naia after House Call) offers no
  49/1, and an out-of-range 26/8/26/10 is refused before the open menu is
  consumed.
- Duplicate 49/14, replayed Talk and replayed 49/2 change no coins, inventory,
  profile XP or save byte; the existing per-character grant key
  (`quest:<character>:<quest>`) pays once.
- Reward coins/XP come only from content (`job_xp` is keyed by profile 11, not
  the active job). No client amount or item id enters `apply_grant`; the reward
  item list is empty, so there is no free item to sell or re-grant.
- The Gordon spawn change is server content, not a client claim: the runtime
  GUID comes from `NpcVisibility`, never from the request, and the existing
  visibility fan-out broadcasts the same actor to every nearby client.
